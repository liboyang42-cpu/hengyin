# 俱乐部 Banner 的母版与复现

`home-banner-club.gif` **不是** `../generate.py` 生成的,是从 `club.mp4` 转的。
母版视频留在这里,不然这张图就成了没人能再生成的孤儿资产。

来源:Apple Fitness「共享体能训练」引导页的录屏(用户提供),文案换成了中文。
⚠️ 画面里的 Memoji、霓虹运动图标、奖章都是 **Apple 的素材**,不是开放授权。
放进商用产品是产品侧知情后的决定,这里只记录事实。

复现:

```bash
python3 assets/covers/home-banners/from_video.py sources/club.mp4 home-banner-club
```

**裁切区不写在这里**,由脚本每次现量:跨帧求非黑内容的并集,再按横向空白带把图形区
和下面的标题/副标题切开,只取上面那段(文案归页面渲染,烤进图里就重影)。
之前这份文档硬写过一组手量的 `crop=757:535:173:271` —— 它和脚本量出来的
`768x548 @ (167,265)` 并不一致,同一个资产两份配方必然分叉,所以删掉了。

中心那三枚 Memoji 圆片也来自这段视频,由 `../extract_memoji.py` 抠出到 `../memoji/`,
供 `../generate.py` 复用 —— 商家/报名两张要和这张是一套,材质就得同源。
