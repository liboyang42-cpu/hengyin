# 游玩页：哪些全屏、哪些弹窗

> 宿主：`pages/play/index`。真源是当前 wxml / wxss 上的用户裁决注释，不是 2026-06 那份过场设计稿。
> 旧稿 `docs/游玩页-深色地图沉浸版-对接说明.md`、`docs/superpowers/specs/2026-06-21-play-page-redesign-design.md` 把「游戏启动 A / 通关足迹卡 / 节点卡」都写成全屏叠加，**已经过期**。改形态先改本文件，再改代码。

一句话：**地图（mode1）或自由探索宫格（mode2）是底。读故事、发勋章、出示票券、集合决策走全屏。到店、答题、选章、结算走底部半屏。确认/扣分才用系统弹窗。**

---

## 1. 怎么选形态

| 要做的事 | 形态 | 为什么 |
|---|---|---|
| 整段叙事、整场仪式、被扫的码、整屏决策 | **全屏** | 底下地图会抢注意力；码还要高对比 |
| 到店动作、答题、选一章、通关小结、玩法组件 | **半屏 sheet** | 人还在路上，要看见地图/宫格 |
| 身份揭晓、碎片翻卡、锁关提示 | **居中卡片** | 一眼读完就关，不占整屏 |
| 进度、开始/暂停、导航读数、券入账 | **HUD / 横幅** | 不是弹层，别再套 `cy-sheet` |
| 结束行程、扣积分、全团操作 | **`wx.showModal`** | 真确认；不要做成半屏表单 |

同屏只允许一层主 overlay。节点卡开着时不要再叠任务页；任务页把节点卡盖住。场景栈 `cy-scene-sheet` 同一时刻只渲一个（见 `scene-sheet-single-host-contract`）。

## 2. 全屏（盖住地图）

这些层 `inset:0` 或等价整屏，打开时地图应被挡住或卸载。

| 层 | 开关 | 何时出现 | 备注 |
|---|---|---|---|
| ~~起始页 `.play-intro`~~ | — | **2026-09-22 下线**:那个开始主题屏只有漫游才有(`pages/roam` 的 intro 是正主)。城市定向改成打开即故事流,地图移到故事流左上角的罗盘后面 |
| 章节正文 `chfull` | `chapterFull` | 底卡标题行展开钮 | 一次一段居中滚动。**不是** 06 月稿里的「首次进章 Ken-Burns 过场」 |
| 旅程手记 | `showJournal` | 底栏工具「旅程手记」 | 开时卸载原生 map，避免和文字流抢合成层 |
| 券票面 `.voucher` | `voucher.show` | 节点卡「本站优惠券」 | 原 `cy-qr-voucher` 弹窗已换成全屏白票 |
| 入场码场景 `qr-ticket` | `sceneCurrent.id` | 底栏核销 / intro 出示码 / 票面「现在核销」 | 注册表 `variant: full`。大码浅底，给商家扫 |
| 徽章 Woo | `medal.show` | 节点发勋章 | 取代旧 `.medal-mask`。底部滑确认「Woo!」 |
| 城市故事信 `.ending` | `ending.show` | mode2 通关叙事 | 弧形长文，不是半屏 |
| 剧情 `cy-story-sheet` | `story.show` | 手记段落「展开」 | 两段式第二段。组件在 `.play` 外面，Scale+Dim 才不会跟着缩 |
| 队伍集合 `.leadgather` | `lead.status==1` | 带队未发车 | 一屏一决策：成员「我到了」/ 队长「开始行程」 |
| 空态 / 加载 | `emptyTip` / `loading` | 没票、没点、拉失败 | 阻断，不是 toast |
| 隐私闸 `cy-privacy-gate` | `privacyGateShow` | 系统要定位授权 | 真弹窗，不压页面栈 |
| 今日城市签 playkit | `playKit` + `dailysign` | 该玩法 | 唯一全屏 playkit（纸质签）。其余 playkit 半屏 |

mode2 首屏宫格 + 镭射卡包是**页面本身**，不是弹窗。

## 3. 底部弹窗（从底下滑上来）

2026-10-03 统一弹窗样式：普通半屏左右和底部贴边，高度不超过 70vh；长内容使用导航下方全高弹窗，顶边按微信胶囊底部 +5px 实测定位。两类都保留原关闭交互，非全屏页面跳转。短提示、短操作以及支付结果这类独立短面板留边；2026-10-03 按用户截图采用 16rpx（375宽下约8px）左右及底部外距，安全区只计一次。

| 层 | 开关 | 高度口径 | 何时出现 |
|---|---|---|---|
| 节点详情 `.sheet` | `sheet.show` | 导航下方全高 | 点图钉 / 到达 / 宫格进店。任务启动页 p02 的故事/规则/材料已经并进这张卡，「开始任务」直接进任务页 |
| 任务页 `.gp2--sheet` | `screen=='gamePlay'` | 导航下方全高 | 扫码 / 填空 / 选项 / 拍照 / 偏好校准。作为原页面上的弹层打开 |
| 章节结算 `.finsheet` | `showFinish` | 导航下方全高 | 通关或本章完成。导航下方全高弹层，底钮叫「继续」 |
| 选章 `.chpick` | `chapterPick.show` | `max-height: 70vh` | 自由探索切章 |
| 高级玩法 `cy-advanced-game` | `advancedPlay.show` | `height: 88vh` | 盲盒 / 分支 / 多人。独立 sheet，不要套进节点卡 |
| 本局线索 | `gameModule.sheetShow` | `cy-sheet` 默认 ≤70vh | 底卡角色名点开 |
| 同行者榜 | `board.show` | 同上 | 结算页次级入口 |
| playkit（除城市签） | `playKit.show` | `cy-sheet` | 盲品、静音点单、步数、音乐角、贴纸、慢任务、时段窗、冠名等 |
| 地点横滑卡 `.pois` | `poiCard.show` | 底栏一条白卡 | 城市定向「切换地点」。多张时露出第二张；单张不留 peek。**不是**旧卡堆半屏 |
| 放弃未保存 | `sceneConfirm.show` | `cy-modal` | 场景栈脏关闭 |

节点卡里的木鱼是**内联控件**，不另开一层。

## 4. 居中卡片（小弹窗）

| 层 | 开关 | 说明 |
|---|---|---|
| 今晚身份 `.rolecard` | `roleCard.show` | 首入本场一次。scrim + 居中玻璃卡 |
| 途中彩蛋 `.eggcard` | `eggCard.show` | 点星白胶囊打开；6s 胶囊自收 |
| 碎片翻卡 `cy-fragment` | `frag.show` | mode2 完成节点；点一下收下 |
| 锁关 `.lockhint` | `lockHint` | mode1 点未解锁钉。无按钮，短时提示「这扇门还没向你敞开」 |

## 5. 不是弹窗：常驻 HUD

不要把这些再做成 `cy-sheet` / 全屏罩。

| 表面 | 说明 |
|---|---|
| 地图 `free-map` | mode1 行走底。手记 / 结算时卸载 |
| 底卡 `.pcard` + 底栏 `.pbar` | 读数 + 开始/暂停/核销/扫码。mode2 **不要底栏** |
| 底栏上滑 `.tools` | 游玩工具。稿上和三键栏是同一张板，中间没有遮罩。注册表里的 `play-session-tools`（peek）**不要再渲成 scene-sheet** |
| 顶栏带领 / 券 toast | 同一 `hud.topBanner` 槽，同时只一张 |
| 导航条 `.navtop` | 直线剩余距离 + 站名，没有逐步转向 |
| 通关 banner / 奖励掉落 `.rdrop` | 贴在地图上的卡片，点开才进结算或收藏 |
| 飞分 / NPC 气泡 / 彩蛋胶囊 | 瞬时反馈 |
| 时间横幅 `.play-timebar` | 活动未开始/已结束，不阻断 |

暂停：**没有**全屏暂停罩。暂停态就是底栏换成「继续 / 结束」。

---

## 6. 系统确认（`wx.showModal` / ActionSheet）

只用于不可逆或要扣资源的决定，不要做成半屏表单。

- 结束本次探索
- 开启定位（拒了就扫码到达）
- 解锁提示（扣积分）
- 查看更高级提示 / 揭示答案
- 队长：解锁下一章、全团结算、广播一句话
- 答案已揭示（只有「我知道了」）

图片预览走 `wx.previewImage`，不是页内 lightbox。

## 7. 从游玩页打开的场景栈

内容在 `cy-scene-sheet` 里，形态看 `utils/scene-registry.js` 的 `variant`：

| 场景 | variant | 用途 |
|---|---|---|
| `qr-ticket` | **full** | 入场动态码 |
| `qr-coupon` / `qr-group-code` / `qr-citynode` | **full** | 其它被扫的码 |
| `play-activity-detail` / `roam-task-list` / `roam-poi-detail` / `roam-discover` / `roam-history` / `roam-session` / `roam-stamp-album` | **full** | 离开地图去读一整页 |
| `game-coupon-wallet` | **half** | 卡券包列表 |

`play-session-tools` 登记为 peek，但实现已经折进 `.pbar`，wxml 不得再为它挂 `cy-scene-sheet`。

## 9. 和旧文档差在哪

| 旧说法 | 现在 |
|---|---|
| 游戏启动页 A 全屏 | 没有 A 页；信息在节点半屏 |
| 游戏进行 B 全屏 | 任务页导航下方全高弹窗 `gp2--sheet` |
| 通关足迹卡全屏 | 结算导航下方全高弹窗 `finsheet` |
| 章节首次全屏 Ken-Burns 过场 | intro 全屏 + 可重看的 `chfull` |
| 券是 toast / 组件弹窗 | 入账 toast 仍在顶栏；出示票面全屏 |
| 节点半屏 + 游戏全屏 | 节点半屏 + 任务也半屏 |

mode1 / mode2 共用这张表。差别只在底（地图 vs 宫格）和有没有底栏，不另搞一套弹层。

## 10. 加新层时

1. 先对第 1 节那张表。
2. 全屏叙事用独立 `view`（参考 `chfull` / `journal` / `woo`），不要 `cy-sheet variant="full"`——那是向导表单白名单。
3. 半屏优先复用页内 `.sheet` / `.gp2` / `cy-sheet` / `cy-advanced-game`，不要新开 page。
4. 写操作仍要带归属；本文件只定形态。
