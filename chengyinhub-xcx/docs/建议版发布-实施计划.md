# 建议版发布 实施计划(可勾选 · 做到哪勾到哪)

> 配套方案文档:`建议版发布-专家方案.md`(同目录)。
> 依赖顺序:**Phase 0 后端预设库 → Phase 1 小程序前端 → Phase 2 web 后台录入 → Phase 3 打磨**。
> 后端在 `chengyinhub-system`(domain/service/mapper)+ `chengyinhub-admin`(controller/web)。本机已有 mvn + JDK21,可 `mvn -o -pl chengyinhub-system -am compile` 验证;部署仍需用户在 IntelliJ 跑。前端验证走微信开发者工具模拟器截图。

**Goal:** 在专业版之外新增单页"建议版"发布流,发布弹窗二选一,数据预填一屏完成,产出标准 topic 复用全部下游链路。

**Architecture:** 前端新单页 `pages/publish/simple` 把"选风格+选路线+减站+填标题/时间/票"拼成现有 `/api/topic/create` payload(自办,触发自动生成可玩活动);后端新增路线预设 CMS(3 表 + 3 只读接口)+ web 后台录入。

## 全局约束(每个任务都隐含遵守)
- 创建仍走 `POST /api/topic/create`,**不新建创建接口、不改 `generateSelfHostActivity`/`checkinCode`/票复制**。
- 建议版固定 `openMerchantPool=0`(自办)、`collaboratorIds=[]`、票 `mode=2`。
- 前端 token 驱动 `var(--cy-*)`,不硬编码颜色。
- 不碰 `pages/publish/fabu`(专业版)。
- 表/字段命名跟随若依风格(`create_by/create_time/del_flag/status`),实体放 `chengyinhub-system`。
