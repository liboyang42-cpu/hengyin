# 上海官方单人城市剧情活动上线调研与点位核验

- 调研日期：2026-08-23
- 调研对象：`migration_seed_official_solo_story_topics_20260823.sql` 中 5 个活动、5 条路线、25 个 GPS 节点
- 调研目标：判断点位是否适合“单人、无商家、无工作人员、自助游玩”的上海 MVP；给出必须调整项、建议里程/时长、统一定价和首批配额
- 证据口径：只采信场馆/产品官网、上海市及区政府、上海文旅/公园管理等一手来源；坐标距离另用迁移文件中的经纬度计算

## 一、执行结论

**当前版本不应直接公开售卖，但不需要重做玩法或增加商家配置。** 25 个地点本身都是真实上海公共地标，24 个可保留原地点，其中西岸 3 个点需要重排先后、桥面/水边/草坪等点需要校准安全 GPS 中心；“末日广播”的世纪大道站必须更换地点。完成调整后，仍须用微信 `gcj02` 坐标在现场实走一次；官方网页只能证明地点和开放属性，不能证明一个 50 米围栏的六位小数坐标在真机上可用。

上线前必须完成的四项内容调整：

1. **替换“末日广播”第 1 站。** 当前“世纪大道地铁站”到“陆家嘴中心绿地”直线约 2.99 km，单段就占整条路线的大部分，破坏故事连续性。改为“陆家嘴站 2 号口地面公共区域”或与其相邻的明珠广场公共区；精确坐标必须现场采集。浦东美术馆官方交通页也以“2 号线陆家嘴站 2 号口”为到达小陆家嘴滨江的公共入口。[浦东美术馆参观指南](https://www.museumofartpd.org.cn/visit)
2. **重排“异常事务局”西岸路线。** 现状为龙美术馆 → 西岸艺术中心 → 油罐 → 西岸美术馆 → 亲水平台，存在南下后折返。应改为龙美术馆（3398）→ 西岸美术馆（2600）→ 西岸艺术中心（2555）→ 油罐艺术中心（2380）→ 江边上层漫步道，形成单向路线。
3. **把所有桥面、水边、草坪节点的 GPS 中心放到硬质公共步道。** 包括乍浦路桥、外白渡桥、中山公园水体、徐汇滨江终点、陆家嘴滨江、复兴公园。节点叙事可以看水、看桥、看树，但玩家站立点不能落在车行道、水体、封闭草坪或养护区。
4. **修正 5 个活动的里程和时长。** 当前 SQL 中前两条路线里程明显高估，陆家嘴线则是由错误首站造成的异常长距离。建议值见第五节。

商业配置拍板：

- **统一首发价：¥19.90/人/主题。** 不免费，不采用 ¥9.90 长期低价；¥19.90 足以验证真实付费意愿，又显著低于成熟海外自助城市剧情产品。
- **首批配额：每主题 100 份，共 500 份。** 不是人为制造稀缺，而是把首批真实世界故障半径控制住；每售完 100 份必须复盘 GPS 失败率、开始率、完成率、退款/客服原因后再补量。
- **首发统一建议游玩时间：09:00–18:00。** 中山公园和滨江虽可夜间开放，但首批是单人活动，且生态观察、水边、桥面和高楼 GPS 在夜间的安全及可用性尚未验证。完成夜间照明和真机定位实测后，再单独开放“末日广播”的夜游版本。

## 二、核验方法与不能被网页替代的部分

### 2.1 路线距离

使用迁移文件内 25 个经纬度计算相邻点直线距离，再以约 1.2 倍作为普通街区步行下限。这个值适合发现明显折返和跨区错误，不等于最终导航里程；最终里程必须用现场实际步行轨迹回写。

### 2.2 公共可达性

判定分为三档：

- **保留**：官方来源能确认地点、地址和公共游览属性，现有文案不要求进馆或消费。
- **条件保留**：地点可用，但精确站位、开放时段、活动管控或安全边界要现场确认。
- **必须调整**：路线明显折返/跨区，或当前落点有车行、临水、封闭空间风险。

### 2.3 研究边界

官方场馆通常只公布地址，不公布适合微信小程序 50 米围栏的 `gcj02` 坐标。上海高楼、桥面、树冠和滨水区域都可能出现定位漂移；因此本报告**不伪造“已现场通过”结论**。发布门槛应是每站至少两台真机、两次冷启动定位均能在安全步道内触发，而不是地图截图看起来接近。

### 4.2 真机现场核验表

每个节点必须记录：

1. 微信 `wx.getLocation({type: 'gcj02'})` 实测经纬度，不从网页或 WGS84 地图抄值。
2. iPhone 与 Android 各一次冷启动定位；高楼/树冠/桥面节点各重复一次。
3. 站在安全人行区是否能进 50 m；站在车道、水边或封闭区外是否不会被迫靠近危险处。
4. 从上一节点的真实步行距离、过街次数、无障碍绕行、厕所/补水点。
5. 正常工作日和周末高峰各走一次；遇临时施工时是否仍有替代站位。
6. 现场照片只拍公共空间，不拍可识别路人正脸，不使用场馆受限素材作为商业封面。

### 6.2 城瘾 MVP 定价拍板

建议固定为 **¥19.90/人/主题，首批每主题 100 份**：

- 比免费更能测真实需求；免费完成率不能证明用户愿意为剧情和路线付费。
- 比成熟海外纯数字产品显著低，符合只有 5 站、尚无大量真实口碑的 MVP 阶段。
- 不采用 ¥9.90 作为常态价，因为它会把完整 60–130 分钟体验锚定成一次性促销品，也无法区分“觉得便宜”与“觉得内容值得”。
- 首批 100 份的目标不是收入最大化，而是得到每个主题至少数十个真实开始/完成样本，同时把错误路线、GPS 漂移和临时封控造成的客服规模限制在可处理范围。
- 100 份售完后不自动扩容。建议达到以下门槛再补 300 份：开始率 ≥70%、开始后的完成率 ≥60%、因 GPS/点位不可达产生的人工求助 ≤5%、退款率 ≤5%，且没有安全事件。

营销上可以发少量平台邀请码给上海本地内容创作者和真实目标玩家，但前台统一标价仍为 ¥19.90；免费体验名额应单独统计，不能混入付费转化。

## 七、是否需要补功能

**不需要为了这 5 个活动新增页面、商家端或复杂游戏编辑器；现有“GPS 节点 + 剧情卡 + 最终分支”足以完成核心体验。** 但发布前必须确认平台已有以下运营兜底；缺任一项就属于 P0，而不是上线后再补：

1. **单主题立即下架/暂停开始**：发生台风、施工、赛事管控或点位失效时，未开始玩家不能继续开新局。
2. **单节点临时替代**：运营可把失效节点改成安全备选坐标，或给已到现场但无法进入的玩家提供照片/剧情兜底，不要求发版。
3. **定位失败可恢复**：至少有重新定位、明确的距离提示和人工申诉入口；不能让玩家在高楼/树冠下无限点按钮。
4. **运营版本和最近场勘日期**：后台能看到路线版本、最近实走时间和修改人；详情页可只显示“最近核验日期”。
5. **分主题数据**：开始、节点到达、完成、GPS 失败、退出、退款/客服原因能按主题查看，否则 100 份配额没有复盘价值。

如果上述能力已有，只需配置和测试，不新增功能。若没有，优先补“暂停开始 + 节点替代 + GPS 恢复”三项；排行榜、社交分享、复杂动画都不是本轮发布条件。
