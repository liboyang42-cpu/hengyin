# 「毛孩子城市探险日」宠物俱乐部 / 社群主理人合作研究

> 研究截止：2026-08-16（中国 / 上海）
> 使用场景：首场独立活动的俱乐部合作计划书与 Figma deck；活动假设为 30–50 组人宠家庭、2–3 小时、3–5 个任务 / 商户节点，另有集合点与终点。
> 研究对象：宠物俱乐部、犬友社群、社区宠友组织及其主理人。
> 证据口径：优先现行法律法规、上海政府部门、场馆 / 活动主办方和行业组织第一方资料；商业案例只用于说明可能机制，不外推效果。
> 重要边界：本文是合作与运营研究，不是正式法律意见。活动日期、路线、场地、保险产品确定后，仍须由具体场所管理方、属地主管部门、保险人及必要时的律师作活动级确认。

## 一、结论先行

### 1. 对俱乐部最有说服力的合作命题

不要把合作卖成“替城瘾发一次招募”，而应卖成：

> **把一次城市活动变成俱乐部的会员关系资产；主理人保留会员关系与品牌，城瘾承担活动产品和现场交付。**

俱乐部真正关心的不是节点数量，而是五件事：会员是否觉得“只有这个社群能带我参加”、主理人要投入多少时间、出事时谁负责、会员和内容会不会被平台拿走、钱何时按什么口径结。首场方案必须逐项回答，不能只展示活动创意。

### 2. 首场合作的推荐交易结构

- 俱乐部身份：`社群合作伙伴`，不是单纯“分销渠道”；是否升级为“联合主办”必须与真实安全职责匹配，不能只为露出而挂名。
- 俱乐部最低投入：建议 `1 名主理人 + 1 名备份联系人`，完成招募内容确认、2–3 次定向触达、成员特殊情况提示与活动后跟进；不要求交出会员名单，不默认要求收款，不默认承担路线 / 商户 / 现场安保。
- 城瘾交付：活动策划、任务系统、路线与节点协调、报名及客服、签到、现场人员、风险评估材料、应急预案、内容交付和对账。
- 首场结算：优先 `固定合作费 + 经核验到场奖励`；只有俱乐部承担明显的招募、主持或内容生产责任时，再考虑净收入分成。不要用未定义的“活动利润”做分成基数。
- 会员数据：俱乐部专属邀请链接 + 聚合漏斗；个人级线索仅在参与者单独同意后回传指定俱乐部。默认不传会员清单、不卖名单、不把活动报名等同于营销授权。

### 3. 首场安全形态的推荐

**推荐首场只接犬只。** 猫与犬的应激、逃逸、防疫和承载方式不同；混合物种会显著增加路线、分区、现场人员和应急复杂度。若商业上必须包含猫，应另设“全程猫包 / 推车、不得落地、独立时段”的封闭小组，并由执业兽医和场地另行确认，不能与犬队伍混走。

首场犬只版建议采用：

- 单一区域 / 单一区内的 3–5 个书面确认节点；优先室外开放空间或明确许可的宠物区域。
- 每批 5–8 组、间隔约 10 分钟错峰出发，不做 30–50 组同时聚集的“发令式”开场。
- 每名成年控犬人最多带 1 只犬；未成年人不能成为唯一控犬人。
- 犬证 / 年审、有效狂犬免疫证明、犬牌、牵引和大型犬嘴套为硬准入；禁止个人饲养的烈性犬不得报名。
- 法律要求牵引带不超过 2 米；首场采用更严格的内部标准：固定式牵引绳建议不超过 1.5 米，伸缩绳锁定或不得使用。
- 不设置犬只速度赛、障碍赛、走秀或表演。若设置名次、竞赛或犬只展示，可能触及《上海市养犬管理条例》第四十条关于犬只展览展示、表演、比赛等大型活动的备案 / 检疫要求，应先向属地区农业农村 / 动物卫生监督部门核实。

### 4. 五个不能靠文案解决的硬门槛

1. **“宠物友好”标签不是通行证。** 上海现行条例明文禁止犬只进入餐饮场所、商场、博物馆等；其他场所也由管理者决定是否允许。首场不把室内商场和餐饮门店设为犬只任务点，户外商业空间亦须逐点取得管理方书面许可。
2. **免责声明不能免掉组织者安全义务。** 群众性活动组织者未尽安全保障义务仍可能承担责任，造成人身损害的免责条款无效。报名页要做风险告知与规则确认，而不是“责任自负”。
3. **30–50 组不等于无需公共安全判断。** 对公众招募且不足 1000 人的活动可能属于上海“小型群众性活动”；场所管理方须风险评估，认为可能影响公共安全或治安秩序时应在活动前 5 日报告属地公安。
4. **保险不能只看保单名称。** 必须让保险人书面确认动物咬伤 / 抓伤、宠物导致第三者财产损失、路线节点、临时工作人员等不在除外责任中；宠物自身医疗通常需另行确认。
5. **会员名单、照片和路线位置不是“合作赠品”。** 报名必需信息、保险信息、照片宣传授权和俱乐部线索回传应分开告知、分开选择。

## 二、研究边界与判断标识

### 1. 城瘾定位的正确表达

计划书中只需出现一次：

> **城瘾是围绕不同兴趣与人群圈层组织城市活动的平台；“毛孩子城市探险日”是本次与宠物俱乐部合作的独立活动 IP。**

不要称城瘾为“宠物平台”“宠物小程序”或暗示后续只服务宠物赛道。

### 2. 本文四类判断

| 标识 | 含义 | 在方案中的用法 |
|---|---|---|
| 法定义务 | 法律、地方性法规、政府规章或有效规范性文件的要求 | 不满足即不准入 / 不开场 |
| 场地规则 | 场馆、公园、商业体等管理者对其管理区域的准入条件 | 逐点书面确认；场地可比法律更严格 |
| 运营基准 | 第一方活动规则或行业团体标准提供的可借鉴做法 | 需结合首场规模和预算裁剪 |
| 城瘾建议 | 基于风险与合作效率提出的内部标准 | 不是法律；合同 / 报名规则发布后按约执行 |

### 3. 当前尚未具备的事实

- 尚无确定日期、区、路线、集合 / 终点、各节点权属及书面许可。
- 尚无售票主体、合同主体、发票主体、保险产品和保险人书面承保确认。
- 尚无合作俱乐部规模、会员画像、历史活动到场率、可开票状态或招募渠道数据。
- 尚无兽医顾问签字确认的犬只健康排除标准。

因此，本文不承诺招募转化率、收入、复购率或“零事故”，也不把任何示例场地视为已获许可。

## 三、俱乐部侧决策研究

### 1. 俱乐部的六个核心问题与可交付回答

| 俱乐部问题 | 主理人的真实担忧 | 首场应给出的答案 / 证据 |
|---|---|---|
| 会员为什么来 | 普通遛狗或商场打卡也能做，活动是否只是换皮 | 有起终点仪式、3–5 个任务、分组社交、完赛纪念与会员专属权益；强调共同经历，不依赖折扣 |
| 我能招到谁 | 公开流量可能不匹配社群，老会员又嫌商业 | 俱乐部专属名额 / 邀请链接；先老会员，再允许会员带 1 位新朋友；报名页展示完整准入规则 |
| 做完能否留下 | 一次热闹后成员沉默，平台带走关系 | 俱乐部保留社群承接；D+1 内容、D+7 反馈 / 会员权益、D+30 下一场预告形成闭环 |
| 我要干多少活 | 主理人担心变成免费客服、收款人、领队和事故责任人 | RACI、联系人和时间投入写进合作单；城瘾负责活动产品、客服、现场和对账 |
| 品牌、照片、会员归谁 | Logo 被稀释、素材不能用、名单被二次营销 | 品牌审批、素材许可、肖像同意、数据角色和删除机制在合作前签清 |
| 钱怎么算 | “净利润”不可核验，退款 / 税费后口径易争议 | 以核验到场或明确净收入口径计费；活动后出逐笔可核对报表，约定退款关闭与结算日 |

### 2. 会员价值：不是“带宠物逛商户”，而是五层体验

1. **身份价值**：俱乐部会员专属批次、队名、领队或限定纪念物，让参与者感知“因这个社群而获得”。
2. **关系价值**：小队任务为陌生成员提供自然破冰；避免需要犬只直接接触的互动，社交围绕人宠故事和共同完成任务展开。
3. **城市价值**：通过经许可的路线和节点看到日常不会注意的城市细节；商户只作为剧情 / 服务节点，不让体验退化为硬性消费巡游。
4. **成就价值**：有明确的开始、进度、终点与可分享成果；首场采用“完成制”而非犬只竞技排名。
5. **照护价值**：入场标准、错峰、休息点、饮水、应急支持和退出机制，让会员感到社群认真对待人和动物。

上海政府平台报道的两个单点案例可以支持“活动—社群—持续黏性”机制，但不能当作首场 KPI：

- 苏河湾万象天地把宠物活动延伸为线上社群；其 2025 年“尾巴摇摆季”期间，项目方披露客流同比增长近 35%、营业额同比增长 10%。这是单一商业体在多品牌、多设施、多活动共同作用下的同期结果，**不是俱乐部活动的可迁移转化率**。原始链接：[上海市政府转载《解放日报》报道](https://www.shanghai.gov.cn/nw4411/20250720/f280511c1ad941759d8c8dbc15cdc7e9.html?siteId=1)。
- 川沙九六广场称定期活动增加用户黏性，并形成超过 300 人的宠物社群。这是项目方口径的场景案例，未披露招募基数、活跃定义和复购数据。原始链接：[浦东新区政府案例](https://www.shanghai.gov.cn/nw15343/20250814/e02df101d07948c08a54990b0760226d.html)。

### 3. 招募设计：保护社群信任的漏斗

#### 推荐节奏

| 时间 | 动作 | 主要负责人 | 对会员说什么 |
|---|---|---|---|
| T-21 至 T-14 | 主理人预热 / 兴趣登记，不收完整报名资料 | 俱乐部 | 活动概念、时间区间、犬只硬准入、预计价格 |
| T-14 | 发布正式报名页与俱乐部专属链接 | 城瘾制作，俱乐部发布 | 完整路线区域、权益、退改、天气、安全与隐私规则 |
| T-10 | 老会员优先截止；释放剩余名额 | 俱乐部确认 | 剩余批次，不制造虚假稀缺 |
| T-7 | 准入资料提醒、候补补位 | 城瘾客服 | 犬证 / 免疫、装备、健康自查、陪同要求 |
| T-3 | 分批时间、集合点和天气提醒 | 城瘾 | 不公开全体参与者名单和手机号 |
| T-1 | 最终天气 / 路线确认 | 城瘾安全负责人 | 是否照常、缩短、改期或取消 |

#### 招募原则

- 采用俱乐部编码 / 专属链接识别渠道，不让俱乐部先导出会员手机号或微信名单。
- 先向现有成员开放，再允许每名成员邀请 1 名符合准入的新朋友；这比无差别公开投放更符合俱乐部关系增长。
- 报名页在付款前展示硬准入、退出权、天气 / 退改、拍摄安排和保险边界，不能付款后才提示。
- 候补只在明确席位释放后转正；到场奖励以签到核验为准，避免按点击或意向名单结算。
- 不承诺“30–50 组必满”；首场先建立各渠道基线。

### 4. 留存设计：把活动后 30 天写进产品

| 阶段 | 会员触点 | 俱乐部价值 | 建议指标 |
|---|---|---|---|
| 活动前 | 分队、自我介绍卡、宠物性格 / 边界提示 | 提前形成安全的弱关系 | 已确认人数、准入通过率、提醒触达率 |
| 活动中 | 小队任务、队内互助、完赛仪式 | 共同经历而非被动围观 | 实到率、任务完成率、主动退出、事件数 |
| D+1 至 D+2 | 俱乐部署名回顾、经授权照片、完赛电子物料 | 形成可分享的社群记忆 | 内容领取率、授权 UGC 数 |
| D+7 | 反馈问卷 + 俱乐部专属福利 / 主题讨论 | 把满意度转成下一次互动 | 问卷率、满意 / NPS、再次参加意向 |
| D+30 | 下一场优先登记或线下小聚 | 检验是否形成持续关系 | 社群活跃、二次活动意向 / 报名 |

指标须同时给出分子与分母。例如“到场率 = 核验到场组数 / 活动前最终确认组数”，不得把兴趣登记人数当报名人数。首场目标应是建立基线和发现阻力，不应在无历史数据时许诺复购率。

## 四、低负担合作模型与 RACI

### 1. 合作设计目标

俱乐部投入应集中在“会员关系不可替代的部分”，城瘾承担“可标准化的活动交付部分”。计划书可明确：

- 俱乐部不默认垫资、收款、开活动发票、审核犬证或处理退款。
- 俱乐部不默认承担路线巡查、节点协调、现场安保、医疗判断和事故定责。
- 主理人可以自愿担任欢迎主持 / 小队领队，但必须完成同一安全培训并纳入保险人员口径。
- 若俱乐部实质参与组织和现场决策，合同和对外署名须如实反映职责；不能对外称“联合主办”，对内却约定其不承担任何责任。

### 2. 首场 RACI

> R = 执行；A = 最终负责；C = 协商 / 审核；I = 知会。下表是商业建议，最终以合同、场地安全协议和保险安排为准。

| 事项 | 城瘾 | 俱乐部 | 场地 / 商户 | 专业方 |
|---|---|---|---|---|
| 活动产品、路线、任务 | A/R | C | C | 兽医 / 安全顾问 C |
| 场地许可、节点区域和承载量 | R | I | A/R | 属地部门按需指导 |
| 风险评估与安全方案 | A/R | C | A/R（其管理场所） | 安保 / 医疗 C |
| 是否需小型活动报告 | 提供材料、推动确认 | I | A/R（依评估判断） | 属地公安指导 |
| 招募物料与报名页 | A/R | C/R（社群触达） | I | — |
| 报名、收款、发票、退改客服 | A/R（推荐） | I | I | 支付 / 票务方 C |
| 犬只准入规则与资料核验 | A/R | 提醒成员 | C | 兽医顾问 C |
| 现场指挥、签到、路线与节点人员 | A/R | 可选 R | 节点 R | 急救 / 兽医联络 R |
| 品牌与内容审批 | R | A（其品牌） | A（其品牌 / 场地） | 摄影方 C |
| 事故处置和通知 | A/R | C / I | R（场内） | 110 / 120、医院、保险人 |
| 活动复盘和结算 | A/R | C / 收款确认 | 按合同 | 会计 / 税务按需 |

### 3. 合作前给俱乐部的“减负包”

城瘾应一次性交付以下模板，而不是让主理人在群里临时解释：

1. 一页活动说明 + 招募长图 / 文案。
2. 一页犬只准入与装备清单。
3. FAQ：价格、陪同、儿童、天气、退改、拍摄、保险、退出。
4. 主理人只需转发的 T-7 / T-3 / T-1 提醒模板。
5. 紧急联系人卡与“群里有人问事故时”的统一回应话术。
6. 活动后聚合数据报告和结算单样例。

## 五、品牌、内容与数据权益

### 1. 权益矩阵

| 权益 | 推荐默认规则 | 必须另行确认的情况 |
|---|---|---|
| 合作称谓 | “社群合作伙伴 / 指定俱乐部伙伴” | “联合主办”须匹配真实组织、安全与对外责任 |
| Logo / 名称 | 仅用于本次活动既定渠道和物料；发布前双方确认 | 后续活动、招商提案、媒体稿、常设官网 |
| 类目排他 | 首场默认不排他；已签同类赞助须提前披露 | 俱乐部要求城市 / 品类 / 时间排他时，写清范围和对价 |
| 现场内容 | 城瘾组织拍摄；俱乐部获得筛选成片的非独占、非转授权许可 | 原片、付费广告、再许可给品牌赞助商、长期素材库 |
| 摄影作品权利 | 与摄影服务方书面约定交付、使用和署名；不等于取得参与者肖像许可 | 第三方摄影师、媒体、达人各自发布 |
| 参与者肖像 | 报名与宣传授权分开；现场提供不拍摄标识和避让区域 | 付费投放、户外广告、招商、AI 训练 / 合成均单独授权 |
| UGC | 参与者主动投稿并选择授权范围；保留署名 / 撤回处理渠道 | 下载后改编、品牌二次投放 |
| 活动数据 | 双方获得完成合作所需的最少数据；俱乐部默认拿聚合报告 | 个体手机号、微信、精确位置、健康 / 保险资料的回传 |
| 会员线索 | 参与者单独选择“同意某俱乐部联系我”后才提供 | 不得用参加活动的同意替代后续营销同意 |

### 2. 数据最小化方案

推荐数据流：

`俱乐部专属链接 → 城瘾报名页 → 城瘾完成报名 / 准入 / 通知 → 俱乐部收到聚合漏斗 → 参与者另行勾选后才回传个体线索`

具体做法：

- 犬证和免疫证明优先现场出示核验，系统只记录“已核验 / 核验时间 / 核验人”，不默认保存证件全图、身份证号和家庭住址。
- 若保险必须采集姓名、证件号、手机号，先以保险方案确认实际字段、接收方、保存期限和删除方式，再在隐私告知中单列。
- 任务系统不默认采集连续 GPS 轨迹；用节点签到与时间戳即可完成运营的，不收精确位置。
- 宠物姓名、品种、体型等一旦与主人账号绑定，仍可能构成可关联个人的信息，按最小必要原则处理。
- 对外复盘默认只提供聚合数据；小样本分组避免使个体被反推。
- 设置明确的访问权限、导出日志、删除期限和事故联系人；活动结束后删除不再需要的证件 / 健康材料。

### 3. 法律依据

- 《个人信息保护法》第六条要求目的明确、直接相关和最小范围；第十四、十五条涉及知情同意和撤回；向另一处理者提供个人信息时，第二十三条要求告知接收方并取得单独同意；第二十五、二十六条限制公开和公共场所图像采集；第二十八至三十一条对敏感个人信息及不满 14 周岁未成年人信息提出更严格要求。原始链接：[工业和信息化部法律全文](https://www.miit.gov.cn/zwgk/zcwj/flfg/art/2022/art_04a0f1fb5df244e39688fd5372623a8d.html)。
- 《民法典》第一千零一十八至一千零二十二条保护肖像权并规范肖像许可。公共环境中“不可避免”的入镜例外不宜被扩张成商业活动宣传授权。原始链接：[国家统计局转载《中华人民共和国民法典》全文](https://www.stats.gov.cn/gk/tjfg/xgfxfg/202503/t20250312_1958939.html)。
- 未成年人由监护人完成报名、风险确认和肖像选择；肖像宣传仍与参加活动分开选择。上博“奇喵夜”要求每名未成年人至少由一名成年人全程陪同，可作高客流携宠活动的运营参照，但不是本活动的法定人数配比。原始链接：[上海市文化和旅游局 / 上海博物馆活动规则](https://whlyj.sh.gov.cn/wbzx/20240715/253d6e7943e746e985925d2a62dcae39.html)。

## 六、收入模型与结算关注点

### 1. 三种模型比较

| 模型 | 适合场景 | 优点 | 主要争议 | 首场建议 |
|---|---|---|---|---|
| 固定合作费 | 俱乐部提供品牌背书和约定触达 | 最易预算、最易开票 | 未定义触达次数 / 物料 / 到场义务 | 可用 |
| 固定费 + 核验到场奖励 | 俱乐部承担招募，但城瘾收款和履约 | 将关系价值与真实交付结合；易核对 | 重复渠道、退款、临时替换如何计数 | **优先** |
| 净收入分成 | 俱乐部承担较深招募、主持或共同制作 | 与收入联动 | “净收入 / 成本 / 退款 / 税费”最易争议 | 首场慎用 |

不建议按“进群人数”“点击”“意向登记”结算，也不建议让主理人向会员个人收款后再转给城瘾。若因俱乐部经营方式必须代收，应另设票款托管、退款、发票、消费者投诉和个人信息安排。

### 2. 推荐计费口径

示例结构（金额待商业确认）：

`俱乐部应收 = 固定合作费 + 单位到场奖励 × 俱乐部渠道核验到场组数 + 经书面确认的额外交付费`

其中：

- “组”以一个有效订单 / 邀请码和现场签到为单位，同一订单多人不重复计。
- 改签至其他场次、退款、未到、工作人员 / 赠票是否计费，合同逐项写明。
- 多渠道归因以首次有效专属链接或下单时主动选择为准，不在活动后人工争抢归因。
- 活动取消时固定费如何处理取决于俱乐部已完成的交付；到场奖励为零或转移至改期场。

### 3. 对账与结算清单

合同至少定义：

1. 售票 / 收款主体、消费者合同主体、发票主体与客服主体。
2. 含税票价、俱乐部专属价、赠票、优惠券由谁承担。
3. `有效报名`、`最终确认`、`核验到场`、`退款`、`改签`、`异常订单`定义。
4. 若分成，收入基数是含税实收还是不含税实收；允许扣除项仅列明退款、支付通道费、约定税费等，不得笼统扣“运营成本”。
5. 天气取消、政府 / 场地方取消、主办方取消、参与者未到、准入失败的退改规则。
6. 赞助费、商户销售、现场增购和周边收入是否进入俱乐部结算；默认互相独立。
7. 对账字段和最小化：订单匿名 ID、渠道、状态、实收 / 退款、签到时间；不因对账暴露完整手机号 / 证件号。
8. 结算日：建议在活动结束且约定退款窗口关闭后 `T+10 个工作日`内付款；这是商业建议，不是法定期限。
9. 对账异议期、补单 / 退款追溯、迟延付款、发票类型和税费承担。
10. 非公司化社群能否签约、收款、开具发票；若不能，由谁作为合法合同 / 收款主体。

### 4. 首场退款建议

为保护社群信任，建议采用公开且简单的规则：

- 主办方、场地或安全原因在活动开始前取消：参与者可选改期或原路全额退款。
- 因官方天气预警触发预先公布的停办标准：改期或退款，不将其模糊归入“不可退”。
- 因参与者未满足已经前置公示的硬准入：退款比例和已发生的不可退成本须提前说明，但不能用隐藏条款临时拒绝。
- 活动开始后的中止、单节点关闭、宠物主动退出如何处理，须在售票前写明。

### 2. 公共场所和“宠物友好”边界

《上海市养犬管理条例》第二十三条禁止携犬进入办公楼、学校、医院、体育场馆、博物馆、图书馆、文化娱乐场所、候车（机、船）室、餐饮场所、商场、宾馆等，亦禁止携犬乘公共汽车、电车和轨道交通；其他场所由管理者决定是否准入。原始链接：[条例全文](https://www.shanghai.gov.cn/nw26192/20200820/0001-26192_27724.html)。

据此，首场路线采用以下保守判据：

- 不把犬只带进室内商场、餐饮门店、博物馆等明文禁入场所；商户任务放在与餐饮经营 / 外摆就餐区物理分离、经权利人书面确认的户外开放区，且不得阻塞通行。
- “宠物友好商圈 / 商场”可能只开放室外、指定楼层或指定商户，不推定全域开放。每个节点在路线图上标出允许区、禁入区、排泄点、撤离点和联系人。
- 公园也非一概开放。上海滨江森林公园游园须知明确禁止携带猫、狗等宠物；而指定宠物区域会另有预约、时段、分区和行为规则。原始链接：[上海滨江森林公园游园须知](https://lhsr.sh.gov.cn/yyxz/20230105/9bbd7cea-558a-43f3-8498-890b7d674eb5.html)、[上海世博文化公园“狗 GO 乐园”](https://www.expoculturepark.cn/pet-park)。
- 上海市绿化市容部门对苏河湾万象天地的调研显示，其犬类管理采用专用地图、商户清单及室内外分区；它能证明“逐区规则”的必要性，不能证明其他商业体当然许可。原始链接：[上海市绿化和市容管理局调研](https://lhsr.sh.gov.cn/ywdt/20230602/1cb138c8-e789-4820-bfc0-31d2f08eb26e.html)。
- 2026 年政府答复显示，《宠物友好型商业场所安全运行管理指南》仍在报批审查阶段，不能当作已生效地方标准，也不能覆盖现行条例。原始链接：[2026 年提案答复](https://www.shanghai.gov.cn/gwk/search/content/2c984a729d935ff9019e06aecf1b1e78)。

中国百货商业协会团体标准 `T/CCAGM 015-2025《宠物友好型商场运营规范》`自 2026-02-01 起实施，可用于参考证件 / 免疫准入、禁入敏感区域、牵引 / 嘴套、咬伤抓伤处置、保洁与活动策划；它是自愿性团体标准，不能替代法律和具体场地许可。原始链接：[协会标准介绍页](https://npo00197u.npoall.com/news/itemid-92723.html)、[协会原始 PDF 链接](http://www.ccagm.org.cn//storage/uploads/file/2026/01/20/团体标准——《宠物友好型商场运营规范》.pdf)。研究时原始 PDF 直连不稳定，因此仅把可由政府答复和协会页面交叉确认的范围作为运营参考，不据此作强制结论。

### 3. 小型群众性活动与场地安全

上海公安规定把“法人或其他组织面向社会公众举办、每场预计不足 1000 人”的活动列为小型群众性活动。公共场所内举办此类活动：

- 场所经营 / 管理单位开展安全风险评估；评估围绕安全方案、防范措施和应急预案。
- 场所经营 / 管理单位认为活动可能影响公共安全或社会治安秩序的，应在活动前 5 日向所在地公安部门报告。
- 公众责任险属于鼓励投保事项。

原始链接：[上海市公安局《关于加强公共场所人群聚集活动安全管理的若干规定》第二、三、十、十二条](https://www.shanghai.gov.cn/nw48968/20200929/0001-48968_64814.html)、[《上海市公共场所人群聚集安全管理办法》](https://www.shanghai.gov.cn/xxzfgzwj/20210608/cb64538755d24ecabc2b490336e39998.html)。

对本活动的含义：

- 若向社会公开售票 / 报名，即便只有 30–50 组，仍可能落入“小型群众性活动”；不能以“不满 1000 人”直接推出“无需任何风险评估”。
- 5 日报告不是所有小型活动由城瘾自动申报，而是场所管理方完成评估后判断。城瘾应向集合点、终点及主要节点管理方提供活动方案，取得“已评估 / 是否报告”的书面确认。
- 仅限既有会员、非公开招募是否构成“面向社会公众”与具体开放方式有关；仍不能免除民事安全义务和场地规则，应请场地 / 属地公安按事实判断。
- 首场建议限定在一个区，避免跨区路线和多套属地沟通；人数预算保守计入参与者、陪同、工作人员、嘉宾和可预见围观者。
- 1000 人以上才进入大型群众性活动安全许可路径；本首场设定远低于该阈值，但若后续扩容，承办者须在举办日 20 日前申请，1000–5000 人由区公安、5000 人以上或跨区由市公安实施许可。原始链接同上及[国务院《大型群众性活动安全管理条例》](https://xzfg.moj.gov.cn/law/detail?LawID=204)。

### 4. 道路、摊位和节点布置

- 普通行人沿人行空间通行不等于取得搭建、摆摊或占路权。未经批准，不得擅自占用城市道路搭建、堆物或从事妨碍交通的活动。原始链接：[《上海市城市道路管理条例》](https://www.shanghai.gov.cn/xxzfgzwj/20210608/024f42f0c5e8405e9c5147cf58c99a48.html)。
- 集合签到桌、拱门、指示牌、拍照装置、排队围栏、品牌摊位若落在道路 / 公共空间，应由权利人和相关管理方确认位置及是否需要手续；不能用“只放两小时”自我豁免。
- 任务不要求参与者站在非机动车道、车行道或消防通道；过街点最少化，工作人员不得以拦车方式组织通行。
- 参与者即时清理犬只粪便是法定义务；节点另设密闭废弃物收集与巡检。原始链接：[《上海市市容环境卫生管理条例》相关官方页面](https://lhsr.sh.gov.cn/srhw6/20240715/d40fbed19b094cbd8f3b367afd0eaf9a.html)。

### 5. 组织者责任、参与协议与保险

《民法典》第一千一百九十八条规定，经营 / 公共场所管理者或群众性活动组织者未尽安全保障义务造成损害的，应承担侵权责任；第三人造成损害而组织者未尽义务的，仍可能承担相应补充责任。第一千二百四十五至一千二百五十一条另规定饲养动物致害、未采取安全措施、危险动物及第三人过错等责任。原始链接：[《中华人民共和国民法典》全文](https://www.stats.gov.cn/gk/tjfg/xgfxfg/202503/t20250312_1958939.html)。

因此：

- 参与者签署规则、风险告知和健康 / 行为声明有助于知情与执行，但不能替代组织者的路线评估、人员配置、现场制止和应急措施。
- 不使用“任何伤亡均由参与者自行承担”“主办方概不负责”等条款。《民法典》第四百九十六、四百九十七条要求格式条款公平并特别提示重大利害关系条款；第五百零六条规定造成人身损害等免责条款无效。
- 即使参与者自愿参加带有一定风险的活动，也不应依赖第一千一百七十六条“自甘风险”替代组织者安全保障义务。

建议保险组合：

1. 以实际承办主体为被保险人的活动 / 公众责任险。
2. 参与者人身意外保障是否另购，按保险产品和收集证件成本决定。
3. 鼓励犬主自行具备犬只责任保险，但不能把它作为组织者唯一保障。
4. 与保险人书面确认：动物咬 / 抓伤、动物引发跌倒、第三者财产损失、工作人员 / 志愿者、所有路线节点、医疗费用限额、免赔额、既往行为、未牵引或违反规则时的处理、宠物自身医疗是否承保。
5. 保单载明的活动名称、日期、地点、人数、被保险人必须与实际一致；合作俱乐部若被对外列为共同组织者，确认是否需列共同被保险人。

上海博物馆“奇喵夜”由主办方为每位观众购买活动保险，并安排外科医生、执业兽医和宠物医疗服务车辆；这是高资源特殊场馆的第一方运营基准，不是 30–50 组活动必须照搬的法定配置。它说明保险与人、宠两条救治链需要同时设计。原始链接：[上海市文化和旅游局 / 上海博物馆](https://whlyj.sh.gov.cn/wbzx/20240715/253d6e7943e746e985925d2a62dcae39.html)。

### 6. 天气、急救与犬伤暴露

上海自 2026-06-01 起施行的新规包含台风、暴雨、高温、雷电等 13 类气象灾害预警，通常按蓝、黄、橙、红四级发布；只有市 / 区气象台可发布官方预警。原始链接：[《上海市气象灾害预警信号发布与传播规定》](https://www.shanghai.gov.cn/nw12344/20260601/5fd69c1c43f24ecbb3a7387f62b12194.html)。

建议把下列内容作为城瘾内部停办线，并在售票前公开；它们不是法规逐字规定：

- T-72 小时看趋势，T-24 小时作预判，T-3 小时由安全负责人根据路线所在区官方预警作最终决定。
- 路线受台风、暴雨、大风等橙色 / 红色预警影响：室外活动延期或取消。
- 雷电黄色及以上影响活动区域：暂停 / 取消室外路线，不能让成员在树下、临时棚下等待。
- 高温黄色：改早晚时段、缩短路线、加密阴凉休息与饮水；高温橙色及以上：室外犬只路线延期。犬只高温照护可参考上海农业农村部门提示：[高温季养宠提示](https://nyncw.sh.gov.cn/bwbdcwl/20230828/8bf36d527b46453db6c513f9cf87bd09.html)。
- 积水、结冰、能见度、空气质量、地表温度或场地临时关闭即使未到统一预警阈值，安全负责人仍有权缩线、停点或取消。

人被犬 / 猫咬伤、抓伤或破损皮肤被舔舐后，现场人员不能自行判断“该犬打过疫苗所以没事”。立即脱离风险、按规范充分冲洗 / 处理，尽快转犬伤处置门诊作暴露分级和医学处置；严重出血、意识异常等拨打 120，现场冲突或犬只失控拨打 110。原始链接：[国家疾控局《狂犬病暴露预防处置工作规范（2023 年版）》](https://www.ndcpa.gov.cn/jbkzzx/c100012/common/content/content_1706568784078565376.html)、[上海徐汇区犬伤门诊与处置提示](https://www.shanghai.gov.cn/nw17239/20250226/87d59e14b69a4608bb0b09a309e20500.html)。

活动前须把最近的 24 小时犬伤门诊、综合医院、动物医院分别标在内部路线图，并电话确认活动时段接诊能力；网页名单不能替代当日回拨。

## 八、首场可执行准入与安全清单

### A. Go / No-Go 硬闸

任何一项为“否”，首场不得按原方案开场：

- [ ] 有明确的合法承办 / 售票 / 收款 / 发票主体，俱乐部签约主体与收款能力已确认。
- [ ] 活动定型为非犬只比赛 / 展示 / 表演；否则已取得属地农业农村 / 动物卫生监督部门对备案、检疫材料的书面结论。
- [ ] 集合点、终点和 3–5 个节点逐点取得管理方书面许可，许可写明携犬区域、时段、人数、布置、拍摄、保洁、用电和紧急联系人。
- [ ] 路线不进入条例明文禁犬场所，不依赖公共交通，不包含未经确认的商场 / 餐饮室内空间。
- [ ] 各场所管理方已收到活动方案并完成其风险评估；是否须在活动前 5 日向公安报告已有书面结论 / 回执。
- [ ] 活动 / 公众责任险已出单，保险人书面确认宠物相关第三者责任不被排除；保单日期、地点、人数、主体一致。
- [ ] 最近犬伤门诊、综合医院、动物医院与交通方案均已当日可用性确认。
- [ ] 参与协议、风险告知、宠物健康 / 行为声明、隐私告知、肖像选择、未成年人监护文件、天气退改规则均已发布并可留存同意记录。
- [ ] 现场总指挥、安全负责人、签到核验、各节点、路线机动、急救 / 医疗联络岗位有人且完成演练。
- [ ] 官方天气 / 场地状态在预设阈值内；无道路封闭、重大活动冲突或场地临时禁宠通知。

### B. 报名硬准入（建议犬只首场版）

- [ ] 每组至少 1 名年满 18 周岁的实际控犬人；每名成年控犬人最多 1 只犬，未成年人不得单独控犬。
- [ ] 犬龄满 3 个月者持有效上海养犬登记 / 年审和狂犬免疫证明；现场佩戴犬牌。
- [ ] 不属于上海禁止个人饲养烈性犬目录，申报品种与犬证 / 现场特征无明显冲突。
- [ ] 主人声明犬只近期无发热、呕吐、腹泻、咳嗽、异常分泌物、疑似传染病或其他不适合外出的状况。
- [ ] 发情、妊娠、近期手术 / 重病恢复、未完成兽医建议免疫程序等情形按兽医顾问最终规则排除或延期。
- [ ] 主人如实申报近期咬伤 / 扑咬、严重资源护卫、易逃脱或在人犬密集环境中无法稳定受控的情形；安全负责人可拒绝或要求退出。
- [ ] 大型犬自备合适嘴套；所有犬只自备牢固胸背 / 项圈与牵引绳，法律上限 2 米，活动内部建议固定式不超过 1.5 米。
- [ ] 自备拾便袋、饮水和犬只专用饮水容器；不共用敞口水碗，不强迫犬只互动。
- [ ] 接受工作人员基于现场行为和健康表现拒绝入场、暂停任务或要求退出；退费按前置规则执行。

> 兽医顾问须在报名开放前确认年龄、疫苗、发情 / 妊娠、术后、慢病和传染病排除标准。本文不替代兽医判断。

### C. 路线与节点检查

- [ ] 单一区内，步行总时长、距离和难度与犬只能力匹配；有短线 / 提前退出方案。
- [ ] 每段路线已白天和拟活动时段各踏勘一次，记录车流、窄路、台阶、玻璃 / 尖锐物、施工、流浪动物、噪声、地表温度和积水点。
- [ ] 过街最少化；无车行道任务、无工作人员拦车、无消防通道和无障碍通道占用。
- [ ] 每节点有最大同时容纳组数、排队线、犬只间距、静默休息区和绕行方案。
- [ ] 不设置犬只直接争抢食物、共用玩具、强制闻嗅 / 接触或速度竞技任务。
- [ ] 商户食品与宠物用品分开；任何犬只试吃品先标成分 / 过敏风险并允许无条件跳过。
- [ ] 签到桌、导视、拍照装置、摊位和用电均在许可范围，无未经批准占路 / 搭建。
- [ ] 每点备水、拾便袋、密闭垃圾袋、基础清洁物、备用牵引和嘴套；消毒用品对人宠安全。

### D. 人员与现场节奏

建议岗位，而非法定比例：

- 1 名现场总指挥：唯一开场、缩线、停点、暂停 / 取消决策人。
- 1 名安全负责人：风险巡查、事故指挥、天气与场地联络；可与总指挥分开以避免顾此失彼。
- 1–2 名签到 / 资料核验人员：只记录核验结果，不在公开队伍中展示证件。
- 每个开放节点至少 1 名节点负责人。
- 约每 8–10 组配置 1 名路线机动人员；最终比例按路线风险评估调整。
- 1 名人类急救联络 + 1 名动物医疗联络；是否驻场医生 / 兽医由风险、保险和预算共同决定。
- 内容人员不得兼任唯一安全岗位。

现场流程：

1. 分批到达，先核验再发放组别标识；未通过者离开聚集区处理。
2. 3–5 分钟统一安全说明：牵引、距离、过街、排泄、禁止接触、退出、事故电话。
3. 每批 5–8 组错峰；上一批离开瓶颈区后再放下一批。
4. 节点负责人可暂停新队进入；参与者可跳过任何任务且不失去完赛资格。
5. 终点也分时到达，不安排所有批次同一时间合影。

### E. 事故 SOP

发生犬只冲突、人被伤、犬只受伤、逃逸或参与者突发疾病时：

1. **先停止活动、隔离风险**：不徒手抓正在冲突的犬，不围观；路线人员封住二次风险点。
2. **救人 / 救宠分流**：人类伤情按 120 / 犬伤门诊路径；宠物按动物医院路径。工作人员不做超出资质的诊断。
3. **必要时报警**：犬只失控、伤人、逃逸、现场冲突或公共秩序风险拨 110。
4. **记录而不现场定责**：时间、位置、当事人、犬证 / 免疫核验状态、目击者、照片、处置与转运；保护无关人员隐私。
5. **通知链**：总指挥 → 场地 → 俱乐部联系人 → 保险人；重大事件按部门要求报告。
6. **暂停相关批次 / 节点**：未排除持续风险不得恢复。
7. **事后跟进**：就医 / 就诊回执、保险报案号、当事人沟通、根因复盘和规则修订；对外信息仅由指定发言人发布。

逃逸另加：保留主人在原地联系人，立即通知前后节点封控、查看监控 / 芯片信息，避免多人追赶造成犬只进一步逃窜；是否联系公安、城管 / 收容力量按现场情况和属地指引执行。

### Deck 中应避免的表达

- “上海最宠物友好的路线”“全程宠物友好”——除非每一段和每个节点均有最新书面许可。

- “俱乐部提供精准私域流量”“我们共享会员资产”。

- 把合作伙伴都写成“联合主办”，却不给安全职责、保险身份和决策权。
- 将城瘾描述成宠物平台或宠物小程序。

## 十一、仍需用户确认的商业与产品决策

这些问题会实质改变 deck、合同和现场方案，不能由研究代答：

1. 首场是否接受“只限犬只”的推荐；若必须有猫，是否接受独立时段、全程载具和更高医疗 / 人员成本。
2. 活动预计在哪个区、日期和时段；集合 / 终点是公共空间、商业体户外还是封闭场地。
3. 是否向社会公开招募，还是仅合作俱乐部定向邀请；每组允许几名成人 / 儿童。
4. 城瘾哪一法人主体售票、收款、开票、签场地与保险；消费者合同主体是谁。
5. 俱乐部合作称谓是“社群伙伴”还是“联合主办”；是否要求排他、主持、领队或内容共创。
6. 首场预算能否覆盖现场总指挥、安全负责人、节点人员、路线机动、保险、人类急救与动物医疗联络。
7. 合作费选择固定费、固定费 + 到场奖励还是分成；预计票价、退款窗口和发票类型。
8. 参与者照片是否会用于仅活动回顾、俱乐部自有渠道、品牌赞助商渠道或付费广告；四种用途授权不同。
9. 任务系统是否采集位置、运动轨迹、宠物健康或保险证件；如采集，业务上为何最小必要、保存多久。
10. 是否设置奖品、排名、走秀、障碍或犬只表演；如有，须先重新判断动物活动备案 / 检疫路径。
