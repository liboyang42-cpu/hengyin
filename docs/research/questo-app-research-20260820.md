## 二、产品机制

### 2.1 Quest 的结构

- 一个 quest = 一条 2–5 km 步行路线 + 沿途 6–12 个地点,每个地点一个谜题,解开当前谜题才解锁下一个地点("Each one you crack unlocks the next location")。以 Montmartre 为例:9 个地点、9 个谜题、2 km、2,630 步、56–86 分钟,起点终点明示到门牌地址。(S5)
- 每个 quest 有一条**虚构叙事**包住真实地点("Every game has a fictional narrative, taking players from one location to the next while roleplaying as a superhero, a detective - or even a cat!",S4)。Montmartre 案例还做了**双角色轮换视角**:情侣各扮一角(Q 和 M),轮流传手机、各自读自己那条故事线,结尾汇合——玩家评论专门夸这个结构。(S5)
- quest 详情页外显信息:难度(Easy/Medium)、平均时长(真实玩家数据)、距离、谜题数、可玩语言(6 种)、被玩次数(Played 8,752 times)、评分分布(74% 五星)、路线起终点、包含的地标清单、XP 排行榜。(S5)
- 商店页描述的表现层花活:互动谜题(如"对着屏幕吹气吹开灰尘露出线索")、剧情内嵌视频、"Time Rifts"(看脚下这个地方几百年前的样子)、"每个 quest 会重塑 app 的视觉皮肤来匹配它的世界观"。(S10)

### 2.2 游玩流程(买→玩→结束)

1. 免费下载 app → 浏览所在城市 quest → 购买解锁(买断制,"yours forever",可无限重玩)。(S2)
2. 走到起点(无预约、无时段,24/7 随时开玩;event 类除外)。(S2, S5)
3. 按故事+线索逐点推进;可随时暂停,关 app 进度保存,回来续玩(计时谜题例外:timer 继续走)。(S2)
4. 结束:终点结算,上城市排行榜;完赛后有 "Memories"(回看全部故事文本)和 "Explorer Photos"(看/传玩家实拍照片)、端内新版还加了 end-of-quest recap。(S5, S10)
- 退款政策:开玩前可全额退;计划游玩时间 24 小时前联系客服即退,24 小时内到账。(S2, S5)

## 三、玩法设计

- **Hint 机制(三层)**:每个谜题内置 Help 按钮——①要提示:扣一些 XP 但能推进;②看完整答案:该题 0 XP,但 quest 继续。即**永远不会卡死**,代价只是分数。(S2)
- **计分/排行**:XP 体系 + 每城排行榜("see where you land on the Paris leaderboard"),玩家有等级头衔(Rookie 等)。(S5)
- **两种节奏模式**:🧭 Adventure(无计时、自走)vs ⏱ Escape(倒计时竞速)。多人可拉 2–200 人分队竞速,终局排行榜。(S5)
- **多人**:Co-op(一台手机共解)/ Versus(分队竞速)/ Crews(常驻小队,队内照片流、争榜)。(S10)
- **离线**:下载解锁后"works offline";单人离线可玩,**实时组队竞速需要联网**;官方建议保留移动数据因 GPS/地图导航要用。(S1, S5, S2)
- **GPS 依赖程度:中低**。GPS 用于导航到点位,但谜题答案来自**观察实体环境**(雕像、建筑、街头艺术上的信息),不是强制 geofence 触发;FAQ 有专门的 GPS 排障条目(设 Always、开 Wi-Fi 辅助定位、远离高楼)。设备要求 iOS 14+ / Android 8+。(S10, S2)
- **家庭/无障碍**:全线家庭友好,有 4–8 岁专门的 "Kid Quest" 产品线;无障碍程度按 quest 标注在详情页。(S10, S2)
- **电量管理**:官方明说一场耗电 15–25%(类比 Google Maps),建议 50% 起玩、带充电宝——把物理世界成本写进预期管理。(S2)

## 四、内容生产(UGC 创作者体系)

- **谁能写**:任何人,免费加入,无技术门槛("If you can write a story and use a map, you can create a quest")。30,000+ 创作者,分布 60+ 国。目前**只支持英文发布**("Quests are currently published in English. More languages coming soon.")。(S3)
- **创作工作流(官方四步)**:①在地图上设计路线选点 → ②给每个点拍照 → ③查每个点的史实/故事 → ④写一条把所有点串起来的叙事。官方结构化数据里标注总耗时 PT168H(约一周业余时间)。工具 = Questo Creator Platform + 带相机的手机。(S3)
- **审核**:上线前必经官方编辑团队人工审("your quest will be reviewed, and you will receive feedback if needed";FAQ:"Quests are reviewed before publication")。先进入 beta 测试期(城市页有 "New Quests…Try these quests in beta" 专区,官方还会**帮找测试玩家**),测试通过才转付费。(S3, S6, S4, S2)
- **分成**:新创作者即拿 **75% 终身流水分成**("As a new creator, you get 75% royalties from all future sales of your games"),官网口径 "earn up to 75% lifetime royalty",无上限无期限,月度结算。搜索摘要中"分成与评分挂钩"的具体阶梯**未能核实**(官网未公开阶梯表)。(S4, S3)
- **版权**:创作者保留署名权(creator credit),Questo 负责托管与分发;具体权利以 creator agreement 为准(协议全文未公开,未能核实)。(S3)
- **配套**:创作指南、模板、编辑一对一反馈、创作者私密社区;官方年度节日活动(情人节/万圣节)给 quest 导流。头部创作者一个月能出 3–4 个游戏;官网展示的明星创作者单人最多 16 个 quest。(S3, S4, S1)
- **官方自制**:"Questo Originals" = 官方编辑部自制/策展的 quest 系列(平台早期未开放 UGC 时的存量),头部爆款(Montmartre 3,099 评价)是 Originals——**头部内容官方自己下场做**。(S5)

## 五、商业模式(B2C 之外)

- **OTA 分销**:TripAdvisor、Viator、GetYourGuide、Fever 四个渠道正式售卖,booking code 换 app 内解锁,FAQ 有整节讲解锁流程——B2C 之外最成体系的一块。(S2)
- **Reseller/合作伙伴计划**:面向 tour operator、旅行社、酒店、旅游局开放申请(questoapp.com/reseller,一张公司信息申请表)。官网页脚 "Become our partner. We are working with top brands worldwide."。白标与分成比例未公开,**未能核实**。(S2, S8, S1)
- **企业团建/教育**:公司用于 team building、onboarding、corporate outing;教师带学生按团价——两者都走人工询价(finance@questoapp.com),无自助 B2B 产品。(S2)
- **Event Quests**:数百人同时参与的定时大型城市活动,专属剧情+竞赛排行,起点提前 1–2 周邮件公布,约 $40/组;18 岁以下随行免费、宠物可带。2024 年融资就是为了买"通用故事"IP 做全球 Event Quests。(S2, S12)
- **Hosted quests(带本地真人主持的场次)**:定时、真人 host 带队玩 Questo quest,app 内给 host 打赏,**host 拿 100% 小费**——轻资产版真人导览。(S1)
- **礼品**:单 quest 礼品 + 时限通票礼品(见 2.3),可定时投递、可打印。(S7)

## 七、对城瘾的可借鉴点

> 城瘾 = 微信小程序,三模式:主题探索(章节故事流,已支持图片/音频块)+ 商家打卡(核销)+ 自由漫游;有专业编辑器给创作者写章节;有商家端。

### 值得抄的

1. **Hint 三层机制 → 章节故事流的谜题块**。Questo 的"要提示扣 XP / 看答案零分但继续"保证玩家永不卡死、流失最小化,同时保住排行榜含金量。城瘾章节剧情屏目前只有内容块消费(图片/音频块),若章节里加互动谜题/答题块,应直接抄这个三层结构:提示按钮 + 扣分显示 + 兜底看答案,而不是做"答不对不给过"的硬闸。
2. **多人票档定价 → 探店日票档**。Solo €12.99 / Duo 省 11% / 5 人 Fellowship 省 39%,默认选中最大档、人均价外显。城瘾探店日(¥149 全含同日局)天然是多人局,可加"双人票/小队票"阶梯,锚定人均价降低拉人门槛——这比单价打折更能带同行转化。
3. **城市 Exploration Pass → 主题打包**。"6 个 quest €39.99,玩到第 4 个回本"这句文案 + 按"I'm visiting / I live here"分流推荐,转化逻辑非常干净。城瘾同城多主题时可做"城市通"或"商圈包",对游客身份推包、对本地人推单主题。
4. **quest 详情页的"事实外显" → 主题详情页**。Questo 把真实玩家数据全部外显:平均时长(56–86 min 区间)、步数、距离、被玩次数、评分分布、难度、起终点门牌地址。城瘾主题页可直接补:真实完成时长分布、章节数、总步行距离、被玩次数——这些数据后端都有,只是没外显,是零成本的信任建设。
5. **创作者四步工作流 + 编辑审核 + beta 期 → 专业编辑器**。Questo 把创作拆成"选点→拍照→查资料→写故事"四个傻瓜步骤,一周出活,然后编辑人工审 + beta 测试区(官方帮找测试玩家)。城瘾专业编辑器已有选点(chooseLocation)和章节编辑,缺的是:①创作向导把四步固化成引导流程;②"beta 主题"公开测试区(灰度可见+专门收反馈),而不是审完直接全量。
6. **完赛资产:Memories + Explorer Photos → 章节回看 + 打卡照片流**。Questo 完赛后可回看全部故事、看其他玩家实拍并上传自己的。城瘾商家打卡已有照片素材、主题探索有章节内容,把"完赛回看 + 本主题玩家照片墙"做成结算页,是把一次性消费变成社区资产的最便宜路径(Questo 新版还专门加了 end-of-quest recap,说明这个位置值得投入)。
7. **官方自制头部内容(Questo Originals)**。平台冷启动期头部爆款全是官方编辑部自己做的,UGC 是放量手段不是冷启动手段。城瘾同理:别指望创作者生态自己长出标杆主题,官方(或签约创作者)先做出 3–5 个"这才叫主题探索"的范本,编辑器的模板就从范本里抽。
8. **物理世界预期管理文案**。Questo 把耗电 15–25%、建议 50% 电量、穿舒适的鞋、看天气、带水写进 quest 页 Tips。城瘾主题开玩前加一屏同款 checklist,成本一小时,减差评。

### 不适用的(及为什么)

1. **买断制卖虚拟内容**。Questo 核心 SKU 是纯数字内容付费(quest 买断 + Gems 内购)。微信小程序 iOS 端虚拟支付被禁,城瘾现有模式(卖的是探店日线下票务 + 商家核销权益,内容随票附赠)恰好绕开了这个坑——**不要**学 Questo 把"内容本身"做成付费 SKU,继续用"线下权益承载付费、内容免费/随票"的结构。
2. **离线包**。Questo 下载后离线玩是 native app 能力;小程序做不了强离线(包体积限制 + 无持久化保证),城瘾不必追,弱网容错(章节内容预加载、打卡请求重试队列)才是对应命题。
3. **OTA 分销 + 多语言**。TripAdvisor/Viator 渠道和 9 语言官网服务的是入境游客盘,城瘾当前盘子在国内本地生活,对应渠道是抖音/美团团购码而非 OTA;booking code 换解锁的**机制**(外部渠道售卖→码→小程序内核销绑定)倒是和城瘾核销体系同构,真要接团购渠道时可参考其 unlock 流程设计(code + email 绑定 + 常见错误 FAQ)。
4. **年票/时限通票**。Questo 年票 €79.99 成立的前提是 3,000+ quest 的存量供给;城瘾当前主题供给量撑不起通票,做了只会稀释单主题收入。等单城主题 ≥20 个再议。

### 城瘾已有、且做得更细的

1. **商家侧**。Questo 的 B2B 只有一张申请表 + 邮件询价,没有商家自助产品;城瘾商家端(核销环、营销 tab、AI 店铺参谋)整整领先一个产品代际。Questo 反向证明了:城市探索游戏平台自己长不出商家运营能力,城瘾"内容游戏 × 商家经营"的双边结构是 Questo 没有的护城河。
2. **真人/商家在场**。Questo 的 hosted quests(真人 host 带队、拿小费)是 2026 年才补的社交层;城瘾探店日从设计起就是"同日局 + 商家现场核销",线下在场感是原生的。
3. **富媒体章节流**。Questo 的内容块 = 文本+图+视频;城瘾章节故事流已支持图片/音频块且玩家端真正消费块流(#734),结构上不落后。差距不在块类型,在 Questo 的**表现层演出**(吹气解谜、Time Rifts、按 quest 换全 app 皮肤)——这类是投入产出比问题,不是能力缺口,可挑"章节主题色/氛围皮肤"这种低成本项先做。

### 8.1 2026-08-20 最终拍板

以下五项已经完成产品拍板，不再作为开发过程中的开放问题：

1. **章节谜题复用现有节点/模板真源。** 城市定向的文字题、单选题节点在章节故事流中即为“谜题块”；块只引用节点，不复制题目答案。新谜题提示免费，使用 Hint 1 / Hint 2 后解谜分上限依次为 70 / 40；不使用提示答对为 100；查看答案为 0 分并以辅助完成继续。辅助完成不得绕过 GPS、扫码、到店等现实校验。
2. **三套数值彻底分离。** 解谜分只用于本次完赛总结和个人最佳；现有探索值 XP 继续按节点完成幂等发放；可兑换积分继续作为权益货币。V1 不把解谜分接入全局榜，也不因提示或查看答案扣探索值。
3. **官方范本固定为 4 个真实主题。** 依次为“历史街区线索局”“夜游建筑观察”“社区生活采样”“三店一章微体验”；由平台官方账号创建并沿用 `is_template=1` 与 `EXPERIMENTAL → PILOT → VERIFIED` 状态。只有真实账号完成验收并进入 `VERIFIED` 的范本才对创作者推荐，禁止前端硬编码假范本。
4. **视觉能力命名为“章节氛围预设”。** V1 只提供 `DEFAULT / NIGHT / ARCHIVE / MOSS / NEON` 五个枚举，保存在章节上；谜题继承所在章节氛围。它只影响城市定向的章节剧情/谜题层，不改地图、导航、通用按钮和状态色，不允许任意色值。
5. **实施顺序固定。** 谜题数据契约与计分记录 → 章节氛围预设和谜题界面 → 两个城市定向范本试跑 → 另外两个范本 → 专业编辑器创作向导。
