# 「毛孩子城市探险日」Figma 定向计划书制作方案

> 版本：2026-08-16
> 统一定位：城瘾是围绕不同兴趣与人群圈层组织城市活动的平台；「毛孩子城市探险日」只是首个独立活动 IP 与验证载体，不是宠物 App 的全部业务。
> 统一图片标识：所有图库照片均标注“活动氛围参考 / 非城瘾项目实拍”，并在页脚保留摄影者与来源。

## 一、共同设计系统

- 画布：16:9，1920 × 1080；安全边距 96–120 px。
- 字体：Noto Sans SC；标题 Black / Bold，正文 Regular / Medium。
- 共同品牌色：黑 `#111111`、奶油白 `#F4F0E6`、电光蓝 `#315BFF`、橙 `#FF6B35`、青柠 `#C7F04B`、粉 `#FF5C8A`。
- 共同图形语言：城市路线、节点编号、行动标签、爪印只作为「毛孩子」IP 的局部符号；平台层使用路线网络和模块块面，不使用全局宠物化图标。
- 事实标识：`事实`、`推导`、`假设`、`待确认`四种角标；未验证经营数字不得伪装成业绩。
- 合规底线：首场默认“户外路线 + 户外或依法可进入的独立节点”；餐饮、商场、宾馆等现行禁入场所不作为默认节点。

## 二、现有总案优化（12 页，不重建）

1. 封面：保留大标题与路线图，在右下加入城市牵犬照片卡；加小标签“首个活动 IP｜城瘾多圈层城市活动平台”。
2. 现状与机会：不新增图片，避免信息拥挤。
3. 城瘾能力：将“宠物活动方案”修正为“城市圈层活动引擎”；在底部标明毛孩子只是首个验证载体。
4. 活动概念：加入户外人宠社群照片作为右侧裁切背景。
5. 报名与出发：将“健康信息 · 摄影授权”改为“必要信息 · 分项授权”；将“一次完成”改为“履约信息与影像授权分项确认”；加入小型咖啡外摆参考图，但不暗示进入室内。
6. 路线与任务：加入公园互动照片；任务节点表述改为户外 / 合法准入节点。
7. 社群价值：加入人宠户外合影，说明照片为氛围参考。
8. 商业合作：保留商业结构，但加入“商户合作须以合法准入和书面确认”为前置条件。
9. 合伙人：改成“首场城市运营联合发起人”，避免加盟、城市永久代理或自动股权暗示。
10. 俱乐部：强化“不交会员名单也能合作”的数据边界。
11. 安全：左侧爪印区域改为多犬公园照片裁切；“宠物准入”改为“逐点准入”；保留六项硬闸。
12. CTA：加“先验证一场，再决定是否复制到下一场 / 下一圈层”。

## 三、合伙人版｜11 页

视觉：黑 / 电光蓝 / 橙 / 奶油白；像一份城市运营蓝图。照片集中在封面、首场旅程、候选人画像与证据室，其他页使用路线、闸门和责任矩阵。

1. **一起办成首场毛孩子城市探险日**：左侧标题与“单场联合发起”徽章；右侧城市牵犬照片；底部 30–50 组 / 2–3 小时 / 3–5 节点。
2. **毛孩子是首个 IP，城瘾是城市兴趣活动平台**：三层图“多圈层平台能力 → 毛孩子首个 IP → 单场上海试点”；明确未来能力可迁移但不自动授权。
3. **为什么现在值得验证**：三张证据卡（携宠出行意愿、上海官方活动、商户联动）；大号提示“方向证据 ≠ 本项目需求 / 利润证明”。
4. **首场长什么样**：横向时间轴“集合—错峰—户外任务—合法准入节点—终点”；嵌一张公园互动图；侧栏写系统与人工双保险。
5. **我们在找谁，你真正投入什么**：四类候选画像 + 40–70 核心小时、6–9 现场人员均标为规划假设；醒目标注“首场不收加盟费”。
6. **城瘾提供什么，你拥有哪块战场**：左右双泳道；城瘾负责策划 / 系统 / 规则 / 复盘，合伙人负责本地验证 / 招募协同 / 现场交付，中间为共同决策。
7. **六周把想法变成可交付活动**：T-42 至 T+14 路线图；T-28、T-14、T-1 三道 Go / No-Go 用红黄绿证据灯。
8. **钱从哪里来，按什么口径结**：收入—直接成本—退款准备—交付费—绩效奖金瀑布；30 / 40 / 50 组三情景全部标“待报价”；不放固定回报率。
9. **共同发起，不共同含糊**：单场合同、双签事项、熔断权、预算 / 事件台账、唯一收退款主体；底部三条“不保本 / 不授城市独家 / 不自动给平台股权”。
10. **签字前，先把证据摆上桌**：12 项证据室网格（产品演示、预算、逐点许可、节点意向、需求订金、保险、退款、隐私、应急等）；状态只用“已备 / 待备”。
11. **先一场，再决定下一场**：申请—访谈—案例核验—联合踏勘—签单场协议五步 CTA；右侧环形闭环“交付—复盘—结算—自然终止 / 另签续约”。

## 四、投资人版｜12 页

视觉：午夜黑 / 奶油白 / 青柠 / 蓝；像一份可审计的验证仪表盘。数字页偏克制，照片只用于封面、首场方案、为什么选宠物，避免用氛围图替代证据。

1. **用一个高参与圈层，验证可迁移的城市活动引擎**：城市牵犬照片占右 45%；左侧写“城瘾＝城市圈层活动平台｜毛孩子＝首个 beachhead”。
2. **城市兴趣社群的断点**：两列问题；用户缺安全、有组织、可持续的共同体验，商户缺可归因的圈层客流；底部一行“微信群 + 表单能办一场，但难形成可复用证据”。
3. **首场：一场可观测的人宠城市探险**：30–50 组、2–3 小时、3–5 个户外 / 合法准入节点；流程与安全边界同屏。
4. **为什么从宠物圈层开始**：情感连接、社群明确、节点丰富、高约束压力测试四项；放社群照片；3126 亿元只作行业背景并大字标“不是活动 TAM”。
5. **首场要验证的不是热闹，是八个假设**：价格、CAC、到场、完成、安全、节点增量、复购、商户续约；每项用“未知 → 读数 → 反证条件”。
6. **从活动流程到可复用引擎**：报名资格—任务—路线—核销—异常—复盘六模块；底部列未来可迁移到亲子 / 骑行 / 摄影等，但标“需另行验证”。
7. **一场的收入，必须经得起拆解**：B2C 家庭票 + B2B 活动 / 节点费 + 品牌赞助 + 可归因增购；单位经济公式与全部待报价项；突出“赞品 ≠ 现金收入，GMV ≠ 平台收入”。
8. **市场规模从交付能力往上算**：bottom-up TAM / SAM / SOM 公式；展示 ¥99 / ¥199 / ¥299 仅为测试价阶梯；标注票务天花板低，venture case 需 B2B 付费与伙伴交付。
9. **竞争不是空白，而是免费供给与低成本替代**：中国坐标 / 它坐标、政府 / 商场免费活动、俱乐部自办、微信群表单四象限；差异化写成待验证命题。
10. **当前没有护城河，资金用于把经验变成资产**：任务模板、合规 SOP、伙伴网络、可归因数据、品牌复购五层；每层对应形成条件和失效证据。
11. **Gate 0–4：一层一层证明平台成立**：需求订金—首场闭环—2–5 场重复—6–20 场伙伴 / 系统—非宠物第二圈层；不要画虚构收入曲线。
12. **本轮资金只买可读回的里程碑**：融资金额、runway 留“待创始人确认”；用途以活动验证、产品数据、安全合规、BD、核心团队、预备金六块呈现；CTA 为“讨论 Gate、数据室与首场联合观察”。

## 五、俱乐部版｜10 页

视觉：奶油白 / 蓝 / 橙 / 粉；更有人情味、最照片化，但仍保持清晰责任和安全边界。照片集中在人宠小队、路线、公园和外摆节点。

1. **你维护会员关系，我们把城市体验跑起来**：右侧人宠社群照片；左侧活动参数与“俱乐部＝社群合作伙伴”。
2. **会员缺的不是一次遛狗，是只属于社群的共同经历**：身份、关系、城市、成就、照护五层价值围绕一张小队路线图。
3. **一次完整的人宠城市探险**：集合—错峰—任务—节点—终点；角落只用一行解释城瘾是多圈层平台，本次只合作毛孩子独立 IP。
4. **俱乐部能留下四类资产**：会员活跃、可控新成员、品牌内容、可核验数据 / 收入；使用社群照片与四张资产卡，不写虚构效果数。
5. **主理人只做不可替代的会员工作**：城瘾 / 俱乐部职责对照；突出“1 主理人 + 1 备份、2–3 次触达”为设计目标而非行业标准。
6. **不交会员名单，也能完成招募和留存**：专属链接漏斗 + D-14、活动日、D+1、D+7、D+30 时间轴；个人级线索只在单独同意后回传。
7. **品牌、照片、会员关系，合作前写清**：Logo 审批、成片使用、付费投放另批、无拍摄标识、最小数据；页面中央为“默认不共享会员名单”。
8. **三种合作模式，钱按可核验结果结**：固定合作费 / 固定费 + 到场奖励 / 明确定义的净收入分成；对账字段、退款窗口、建议 T+10 工作日结算。
9. **可参与，首先要可安全退出**：犬证 / 免疫、牵引 / 嘴套、错峰、可跳过任务、双路线医疗转介、保险六个硬闸；用多犬公园照片表达空间与分组。
10. **首场验证四件事，再决定是否复制**：招募可行、体验完成、风险受控、合作可复用；列实到 / 完成 / 事件 / 满意 / D+30 意向；CTA 为“交换合作包—确认一场—共同复盘”。
