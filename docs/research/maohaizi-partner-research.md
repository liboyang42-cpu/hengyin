# “毛孩子城市探险日”城市运营合伙人 / 联合发起人研究

> 研究范围：中国、上海；信息截点：2026-08-16
> 对象：首场单独活动的城市运营合伙人 / 联合发起人，不是投资人，也不是普通俱乐部
> 已知活动假设：30–50 组人宠家庭、2–3 小时、3–5 个任务 / 商户节点、集合及终点场地；城瘾提供活动策划、任务系统、路线与商户组织。
> 说明：本文是商业与产品研究，不替代针对具体路线、场地、合同和活动属性的正式法律意见。

## 0. 结论先行

最适合首场招募的不是“愿意交钱买城市的人”，而是**能在上海把一场受控试点交付出来的城市运营者**。对外一句话应是：

> **先共同办成一场，再决定是否共同经营一座城市。**

核心判断：

1. **把合作限定为单场。** 首场使用《单场活动联合运营协议》，有明确预算上限、职责、决策权、事故与退款责任、结算和终止日；不要先授予城市独家、长期代理、跨 IP 权利或股权。
2. **不收加盟费，不公开募资，不保收益。** 若需对方垫付，只能是书面预算内、凭票据、设上限和偿还顺序的项目垫款；首场更优方案是“交付费 + 经验证的绩效奖金”，而不是“现金入伙 + 回本承诺”。商业特许经营、招商广告和非法集资各有独立边界，不能靠改称“城市合伙人”规避。[S12][S13][S14]
3. **本活动是城瘾的第一个单独活动 IP，不是城瘾的品类定义。** 城瘾应被描述为围绕不同兴趣 / 人群圈层组织城市活动的平台；毛孩子是首个验证载体。合伙人未来可复用的是城市资源整合、现场交付和商户协作能力，但任何其他圈层合作都须另行评估、另行授权。
4. **上海有明确的方向性机会，但没有本项目的需求或利润证明。** 2026 年上海赛事经济行动方案已明确提出城市定向要聚焦宠物等消费需求，并加强商业主体、主题线路和互动任务联动；上海官方活动也验证了“任务节点 + 商户权益 + 家庭参与”的形式存在。[S4][S5] 这些材料不能证明城瘾能获得 30–50 组有效报名，更不能证明首场盈利。
5. **场地合规是首要外部闸门。** 现行《上海市养犬管理条例》仍列明办公楼、餐饮场所、商场、宾馆等为犬只禁入场所；其他场所由管理者决定是否允许进入。与此同时，2026 年官方文件又显示上海正试点宠物友好商业空间、相关地方指南仍在报批、养犬条例仍处修法前期。[S1][S2][S3] 因而“宠物友好”宣传不等于活动可入内，首场应默认采用**户外路线 + 户外 / 独立许可节点**，逐点取得写明宠物数量、区域、时段和管理措施的书面同意。
6. **“探险日”是否构成体育赛事或犬只比赛不能自行下结论。** 如果存在计时、排名、竞赛规则和奖项，应在开售前向属地区体育部门确认活动属性；如果可能被认定为犬只展览、表演或比赛，还需向属地区动物卫生监督相关部门确认备案和检疫材料。[S1][S7] 30–50 组低于大型群众性活动 1,000 人的国家许可口径，但这不等于“无需任何手续”。[S8]
7. **招募 deck 的任务不是讲一个大故事，而是降低合伙人的不可控风险。** 最能促成签约的不是市场规模，而是：产品真机演示、预算三情景、场地书面许可、商户意向、需求订金、保险报价、单场协议、RACI、取消 / 退款机制和退出清单。

## 1. 定位：这个角色是什么，不是什么

### 1.1 推荐的公开定义

**城市运营联合发起人**：以一个上海试点活动为合同边界，贡献本地资源验证、招募协同、现场团队和交付管理，与城瘾共同对首场体验、安全和商业结果负责的独立合作方。

### 1.2 必须与三个相邻角色切开

| 相邻角色 | 核心贡献 | 本角色为何不同 |
|---|---|---|
| 投资人 | 资本、治理或股权价值 | 首场合伙人以本地交付和资源整合为主，现金能力只应是低权重项；不默认取得股权或被动收益 |
| 普通俱乐部 | 带来一个社群、成员或领队 | 城市运营合伙人还要验证场地和商户、组织现场团队、管理预算与风险、交付跨节点体验 |
| 加盟商 / 区域代理 | 付费复制品牌与统一经营体系 | 首场是单次联合运营试点，不出售长期城市经营权，不收加盟费，不自动获得其他活动 IP 权利 |

### 1.3 名称风险

“合伙人”是市场称谓，不应被误解为法律结构。若双方为共同事业共享利益、共担风险，民法典可能适用合伙合同规则，其中包括合伙债务的连带责任；登记为普通合伙企业还涉及无限连带责任。[S11] 因此：

- 招募材料可用“城市运营合伙人 / 联合发起人”，但合同标题建议用《单场活动联合运营协议》。
- 协议要明确双方是否共同承担亏损、谁可以对外签约、谁收款、谁开票、谁处理退款和事故。
- 不能只写“双方独立、非合伙”就认为风险消失；应由律师按真实权利义务判断合同性质。

同理，若个人长期受城瘾考勤、排班、过程指挥并领取固定劳动报酬，“合作协议”标签也不能排除劳动关系；官方规则与指导案例均强调按实际管理和从属性判断。[S15]

## 2. 真实决策问题：候选人签约前到底在判断什么

| 候选人的问题 | deck 必须给出的答案 | 签约前证据 |
|---|---|---|
| 这是一次项目合作，还是让我买一座城市？ | 单场、固定起止日、无默认独家、续约另签 | 单场协议摘要、权利清单 |
| 城瘾到底已经有什么？ | 只陈述已可演示的策划、任务系统、路线与商户组织能力，列出已知缺口 | 端到端真机演示、功能 / 人工兜底清单 |
| 我具体负责什么，城瘾负责什么？ | 每项只有一个 A（最终负责），写出批准权和否决权 | RACI、决策矩阵、联系人 |
| 我要投入多少时间、人、资源和钱？ | 分阶段工时、最低现场编制、资源交付物；现金有上限且非加盟费 | 工时预算、人员表、采购预算 |
| 收入按什么口径分？ | 票款、赞助现金、商户现金与实物分开；先扣哪些成本、何时结算 | 三情景预算、结算样表、票据规则 |
| 如果卖不够 30 组怎么办？ | 预售截止、Go / No-Go 公式、取消与退款责任 | 预售仪表盘、取消流程 |
| 出现咬伤、宠物走失、天气或投诉谁做什么？ | 安全负责人、熔断权、医疗 / 兽医联络、保险、记录和对外口径 | 应急预案、保险报价、演练记录 |
| 商户和场地真的同意宠物进入吗？ | 不以“宠物友好”标签代替书面许可 | 场地协议、逐节点确认函、区域图 |
| 我能不能使用参与者名单做自己的业务？ | 仅按约定目的和最小权限处理；不得默认复制、导出或二次营销 | 隐私告知、处理者角色、删除证明 |
| 首场结束后我得到什么？ | 已结算报酬、可引用的经批准案例、复盘结果；不自动获得股权 / 城市权 | 结算条款、案例授权、数据报告模板 |
| 什么条件下继续合作？ | 以需求、安全、交付、经济性和协作五类 KPI 复审 | 试点评分卡、续约门槛 |
| 我如何退出？ | 便利解除 / 违约解除 / 熔断、费用归属、数据删除、未结客诉处理 | 退出清单和最长结算期限 |

## 3. 外部证据：机会成立到什么程度

### 3.1 可以支持的判断

- **形式有政策与案例基础。** 上海 2026–2028 赛事经济行动方案明确提出，城市定向要聚焦亲子、女性、悦己、宠物等需求，并与商业主体、主题线路和互动任务联动；同时要求安全风险评估、医疗急救、交通疏导和熔断机制。[S4]
- **商户节点可以成为体验和消费连接器。** 2025 中国坐标上海站采用多主题线路、近 200 个点标；官方披露联合近 70 家商家、48 个商业类点标，并把优惠券、节点任务和赛后嘉年华结合。[S5]
- **小规模人宠活动已有接近本首场的公开样本。** 2025 普陀职工宠物友好活动每场 50 人、1 小时，包含签到、闯关、市集和携宠规则；规则覆盖牵引 / 箱包、嘴套、清洁、禁止擅自喂食、攻击行为劝离。[S6]
- **更大规模样本显示“互动—消费”可被有意设计。** 2025 闵行人宠友好狂欢节披露约 200 组携宠家庭参加 1 / 2 公里活动，并以互动打卡奖励导向市集；另一场官方活动采用“政府搭台、企业联动、市民参与”，整合商场、街道、协会与近 50 个摊位。[S16][S17]
- **上海已有可供筛选的户外宠物友好场景。** 2026 年浦东官方答复称，全区有 21 座宠物友好公园、3 公里生态宠物漫步道及若干开放滨水空间，并列出多个宠物友好商业载体。[S3] 这只是候选池，不是活动使用许可。

### 3.2 不能从这些材料推出的结论

- 不能推出城瘾首场有 30–50 组付费需求；需要本项目自己的可退订金 / 付费预售证据。
- 不能把大型官方赛事的客流、赞助或商户数平移到小型商业试点。
- 不能用政府鼓励方向宣称“政府背书”“官方指定”或必然获得补贴。
- 不能把“到场人数”“曝光量”当作商户销售增量；必须设计可核验的核销、到店和复购指标。
- 不能从行业增长或宠物友好空间数量推导首场 ROI。公开官方活动材料普遍不披露完整预算、伤害率、退款率、获客成本和赞助合同。

## 4. 候选人画像与筛选

### 4.1 优先画像

1. **本地活动运营者 / 社区商业主理人**
   优势：能落地、懂场地与供应商；风险：未必懂宠物行为与社群招募。
2. **宠物社群主理人升级型**
   优势：有真实信任和首批种子用户；风险：可能把粉丝量等同交付能力，缺预算、合同和现场安全能力。
3. **宠物友好商业体 / 品牌活动负责人**
   优势：场地、商户、赞助资源强；风险：审批周期、品牌排他和数据诉求可能过重。
4. **城市漫游 / 户外活动策划人**
   优势：路线、任务和现场节奏强，且能力可迁移到其他兴趣圈层；风险：需要补宠物准入、动物福利与犬只冲突处置能力。

### 4.2 推荐筛选记分卡（100 分）

| 维度 | 分值 | 可接受证据 |
|---|---:|---|
| 30 人以上线下活动交付与复盘能力 | 25 | 2 个项目材料、预算 / 排班 / 复盘、2 位可回访推荐人 |
| 上海场地、商户与供应商资源的可验证性 | 20 | 明确联系人、过往合作、7 天内可完成的引荐清单 |
| 真实社群触达与招募转化 | 15 | 历史报名 / 到场 / 退款数据，不只粉丝截图 |
| 安全、宠物管理和应急意识 | 15 | 风险清单、案例问答、路线踏勘方法、愿意购买保险 |
| 商业与预算纪律 | 10 | 报价、票据、变更控制、利益冲突披露 |
| 协作、数据与复盘能力 | 10 | 周报样例、问题升级习惯、数据最小化意识 |
| 可承受的经批准项目垫款 | 5 | 只验证上限，不以“越有钱越适合”排序 |

### 4.3 一票否决

- 只谈城市独家、被动收入或“回本周期”，不愿承担现场交付。
- 要求把票款收进个人账户，拒绝共同预算、票据和对账。
- 拒绝路线全程踏勘、场地书面同意、保险或事故记录。
- 只有流量 / 群人数，没有可核验的到场和履约案例。
- 把“宠物友好”理解为可带宠进入所有商户，或主张用免责书替代安全措施。
- 未经同意要求复制参与者名单、定位或联系方式做二次营销。
- 对外承诺政府背书、必赚、零风险、永久城市权或尚未演示的系统能力。

## 5. 首场投入：时间、资源、现金

以下为**30–50 组、3–5 节点的排期假设**，不是行业标准，应在候选访谈和报价后校准。

### 5.1 时间投入假设

| 阶段 | 合伙人负责人投入 | 主要交付物 |
|---|---:|---|
| T-6 至 T-4 周 | 5–8 小时 / 周 | 场地 / 商户验证、招募渠道、当地风险清单 |
| T-3 至 T-2 周 | 8–12 小时 / 周 | 路线踏勘、人员与供应商、预售与社群答疑 |
| T-1 周 | 15–25 小时 | 全流程彩排、名单、物料、天气 / 取消判断 |
| 活动日 | 8–12 小时 | 进场、执行、事故 / 投诉记录、撤场 |
| T+1 至 T+7 | 4–8 小时 | 对账、商户回访、客诉关闭、复盘 |

合计约 **40–70 小时 / 名核心负责人**。deck 中应写区间和任务，不应写成“每周轻松兼职几小时”。

### 5.2 现场资源假设

- 1 名本地总控（合伙人本人或指定负责人）。
- 1 名路线 / 安全负责人，不与总控兼任熔断后的全部处置工作。
- 3–5 名节点负责人，每个开放节点至少 1 名。
- 1 名机动人员负责掉队、突发、物料和信息回传。
- 集合 / 终点另按入场节奏配置签到、秩序与急救支持。

因此初版应按 **6–9 名现场人员**报价和排班，再经路线、分批出发方式与场地容量校准；不要把志愿者当作“零成本、零管理”的确定资源。体育赛事规则亦要求组织方对志愿者进行招募、培训、保障和激励。[S7]

### 5.3 现金投入原则

首场**不建议向合伙人收取加盟费、城市代理费、席位费或品牌保证金**。若合伙人需要垫付：

- 仅限双方书面批准的预算科目；
- 每笔有上限、票据和采购责任人；
- 明确取消时谁承担、何时偿还、垫款是否优先于收益分配；
- 实物赞助单独登记公允用途，不计入可分配现金收入；
- 未经书面变更不得追加。

首场现金预算至少应列：场地 / 押金、保险、物料、人员、清洁、摄影（如有）、支付费、招募投放、备用节点、医疗 / 宠物应急和退款准备金。**没有本地报价前不在招募 deck 写固定投入额。**

## 6. 职责边界与治理

### 6.1 推荐 RACI

| 工作流 | 城瘾 | 城市运营合伙人 | 共同决定 |
|---|---|---|---|
| 活动 IP、核心体验与任务内容 | A/R | C | 重大在地适配 |
| 任务系统配置与可用性说明 | A/R | 测试、反馈 | 上线 / 人工兜底 |
| 路线与商户组织框架 | A/R | 本地核验、引荐、落地 | 最终路线与节点名单 |
| 场地 / 节点书面许可 | 提供模板、审核 | A/R 获取并核验 | 未取得则 No-Go |
| 本地招募与社群运营 | 内容 / 品牌审核 | A/R | 渠道预算、公开口径 |
| 现场人员、培训与排班 | 标准 / 培训材料 | A/R | 演练验收 |
| 安全、宠物规则、应急 | 制度与风险审查 | 当地执行与记录 | 双方均有熔断权 |
| 定价、预算、赞助和收益 | 财务口径与审批 | 本地报价 / 商务建议 | 双签 |
| 收款、开票、退款、保险 | **待用户指定单一 A** | 配合 | 不得双头收款 |
| 数据处理与客诉 | 系统 / 规则责任 | 最小权限执行 | 数据角色、保留期 |
| 复盘与续约 | 数据汇总 | 当地复盘 | 是否进入第二场 |

`A` = 最终负责，`R` = 执行，`C` = 被咨询。任何工作流不得有两个未区分的 `A`。

### 6.2 治理机制

- **一场一预算、一场一合同、一场一结算。** 不把首场与城市长期权利捆绑。
- **四张共用表：**里程碑、预算、风险 / 问题、决策记录；所有公开承诺可追溯到批准人。
- **变更控制：**价格、容量、路线、节点、宠物准入、退款和赞助权益只能双签变更；安全事项任一方可暂停。
- **沟通节奏：**T-6 至 T-3 每周一次；T-2 至活动日每 2–3 天一次；活动日单一指挥链；T+2 初复盘、T+7 商业复盘。
- **利益冲突：**合伙人推荐关联供应商必须披露关系和比价；不得从商户收取协议外返点。
- **权限：**未经书面授权，合伙人不得以城瘾名义签长期合同、借款、授予城市权或对外承诺收益。

## 7. 收益模型、ROI 与结算

### 7.1 收益不应只写“分成 X%”

统一使用以下口径：

```text
现金收入 = 实收票款 + 赞助现金 + 商户现金合作款
可分配贡献 = 现金收入
             - 已退款 / 拒付
             - 税费与支付费
             - 双方预先批准的直接活动成本
             - 尚未关闭客诉 / 退款准备金
```

商户折扣、礼品、场地减免和其他实物赞助单列，不冒充现金收入。任何分成必须说明基数是票款、现金收入还是可分配贡献。

### 7.2 首场推荐报酬结构

优先采用：

1. **里程碑交付费**：场地 / 节点落地、全流程演练、活动日交付；
2. **经批准费用实报实销**：有上限和票据；
3. **绩效奖金**：只绑定双方可共同控制并可核验的指标，如达到付费 Go 线、现场交付、安全和结算时效；
4. **可选贡献分成**：仅在收入和成本口径锁定后适用，不承诺最低收益。

不建议首场使用“纯利润分成”：它会把定义不清的成本、延期和负现金流全部转成争议；也不建议写“保底回本”。

### 7.3 ROI 现在不能准确计算

当前缺少票价、渠道获客成本、场地、人员、保险、物料、税费、退款政策、赞助和双方工时成本，不能给出可信 ROI。签约前至少提供 30 / 40 / 50 组的三情景：

```text
单组贡献 = 含税实收票价 - 单组变动成本 - 单组渠道 / 支付成本
盈亏平衡组数 = 固定直接成本 / 单组贡献
项目 ROI =（可分配贡献 - 双方计价投入）/ 双方计价投入
```

Go 线应为：`max(体验最低组数, 盈亏平衡组数, 安全可承载下的商业最低组数)`。若结果高于 50 组，首场模型本身不成立，而不是让合伙人承担缺口。

## 8. 收益之后：续约与退出

### 8.1 单场自然终止

建议合同在以下事项全部完成后终止：参与者退款 / 客诉关闭、供应商和双方结算、事故追踪、数据归还 / 删除、物料和 IP 停用、经批准案例素材交付。

### 8.2 提前退出

- **便利解除：**公开售票前可提前若干日退出，按已批准且不可撤销成本分担。
- **立即解除：**重大虚假陈述、私收款、擅自使用名单、严重安全违规、擅自授予品牌权益或拒绝熔断。
- **天气 / 政府 / 动物疫情等熔断：**按预先公布的取消、改期和退款规则处理；体育赛事管理办法要求在不再具备办赛条件时启动熔断。[S7]
- **退出不消灭未了责任：**退款、客诉、数据泄露、知识产权和事故处理继续有效。

### 8.3 续约不自动发生

达到试点门槛后，双方才能讨论第二场、其他兴趣圈层或城市级合作。可以承诺“优先复审 / 优先洽谈”，不能承诺永久独家或自动获得其他活动 IP。

## 9. 首场里程碑与 Go / No-Go

| 时间 | 必须完成 | 闸门 |

| T-42 至 T-35 | 合伙人尽调、单场协议、主体 / 收款 / 发票、预算 v1、宠物种类和活动属性初判 | 商业定义未锁则不对外招募 |
| T-35 | 2 个集合 / 终点候选、5–8 个节点候选、全路线桌面审查 | 有明显禁入 / 交通硬伤则换线 |
| T-28 | 场地书面许可、3–5 节点意向、系统端到端演示、保险报价、退款与隐私草案 | 任一核心证据缺失则不开售 |
| T-21 | 带宠实地踏勘、10 组以内封闭测试、现场排班、应急 / 备用节点 | 测试不能完整走通则停发售 |
| T-14 | 实付报名或可退履约金需求读数、完整报价、三情景预算 | 按公式决定继续 / 缩容 / 取消 |
| T-7 | 路线与任务冻结、名单与宠物材料、人员培训、天气与动物疫情监测 | 不接受未经风控的临时加点 |
| T-1 | 全员桌面演练、物料、通讯、急救 / 犬伤门诊与兽医联络、熔断口令 | 安全负责人签字后才执行 |
| T 日 | 分批出发、节点回报、事件台账、终点核人 / 核宠、撤场 | 严重事件零容忍，任一方可熔断 |
| T+2 / T+7 / T+14 | 初对账；体验 / 商户 / 合伙人复盘；最终结算或保留未结客诉准备 | 完成评分后再讨论下一场 |

建议的**待确认试点阈值**：30–50 组有效报名（付费活动按实付；免费活动按可退履约金或二次确认）、到场率 ≥85%、任务完成率 ≥80%、严重人身 / 动物安全事件 0、人员或宠物走失 0、节点续作意愿 ≥80%、直接贡献不为负、T+14 完成无争议部分结算。除“30–50 组”为当前活动目标外，其余是建议阈值，不是外部行业基准。

## 10. 合伙人签约前应看到的证据室

1. 城瘾签约主体、收款主体、开票能力、品牌 / 内容使用权说明。
2. 参与者从报名、付费、任务、完成到售后的真实演示；明确哪些功能已上线、哪些靠人工。
3. 单场底稿：活动说明、路线、3–5 个任务节点、集合 / 终点、容量与分批节奏。
4. 30 / 40 / 50 组三情景预算、现金流时间表和结算样单。
5. 场地书面许可、商户节点意向、逐点携宠规则和备用节点。
6. 真实需求证据：候补名单不够，至少要有可退订金或付费预售及渠道归因。
7. 风险登记册、天气 / 动物疫情熔断、犬伤 / 人伤 / 走失 / 投诉处置和演练记录。
8. 公众责任 / 意外险及适用宠物活动的承保范围、除外责任和理赔联系人；上海官方城市定向报名费也明确包含保险，但这只说明保险是成熟赛事成本项，不代表其产品适用于本活动。[S18]
9. 参与者条款：真实经营者、价格与包含项、宠物准入、风险提示、取消 / 退款、影像、投诉渠道。
10. 隐私材料：收集字段、处理目的、双方角色、最小权限、保留期、删除和事故通知。行踪轨迹和不满 14 周岁未成年人信息属于敏感个人信息，处理通常需单独同意；未满 14 周岁还需监护人同意和专门规则。[S10]
11. 合伙人 RACI、授权边界、费用票据规则、绩效口径、退出与续约条款。
12. 如果首场没有历史经营数据，应明确写“首场试点”，不能用其他项目或行业数据伪装城瘾业绩。

## 11. 主要风险与控制

| 风险 | 为什么重要 | 最小控制 |
|---|---|---|
| 室内 / 商户节点禁入 | 现行上海条例列举餐饮、商场等犬只禁入场所 | 户外优先；逐点书面许可；必要时向属地公安 / 商务 / 场地方书面确认 [S1][S2] |
| 活动属性不明 | 计时排名可能进入体育赛事管理；犬只比赛等可能涉及备案 / 检疫 | 开售前提交活动说明向属地区体育和动物卫生监督相关部门确认 [S1][S7] |
| 动物冲突、应激、咬伤、走失 | 犬主 / 管理人有动物致损责任，组织者也负安全保障义务 | 证件 / 免疫、牵引、嘴套、分批、间距、劝离、双重核人核宠、保险与事件台账 [S1][S9] |
| 天气、动物疫情、交通 | 城市跨节点活动暴露在持续变化环境 | 官方预警监测、备用路线 / 节点、明确熔断人和退款规则 [S4][S7] |
| 参与者条款失真 | 经营者须真实全面说明服务、安全风险和格式条款 | 显著展示主体、价格、风险、退改、投诉；“免责”不替代安全保障 [S9][S20] |
| 数据越权与二次营销 | 路线位置、未成年人信息可能属敏感信息 | 最小收集、单独同意、角色 / 权限 / 保留期、禁止私自导出 [S10] |
| 合伙 / 劳动关系错配 | “合伙人”或“合作”标签不决定实际法律关系 | 实质匹配的单场合同；优先与有主体的独立运营方合作；律师审阅 [S11][S15] |
| 特许经营或公开募资化 | 品牌 + 统一模式 + 持续支持 + 收费可能构成特许；公开收钱并许诺回报风险更高 | 首场不收加盟 / 代理费，不卖城市权，不公开吸收资金，不保收益 [S12][S13][S14] |
| 商户价值不可验证 | 到场与曝光不是销售增量 | 唯一券码 / 任务码、到店 / 核销、商户回访、基准期；不承诺销量 |
| 产品能力过度承诺 | 首场系统故障会转化为现场与退款风险 | 真实演示、容量测试、已知缺口、人工兜底、现场支持 SLA |

## 12. 招募中应避免的承诺

不要写：

- “保本、稳赚、X 天回本、被动收入、零风险”；招商类广告不得对收益作保证性承诺。[S14]
- “交一笔钱即可成为上海独家 / 永久城市合伙人”。
- “首场即享股权”“自动成为公司股东”“享有平台全部活动分成”。
- “政府支持 / 官方背书 / 指定项目”，除非有可公开的书面文件。
- “无需审批 / 备案”“所有宠物友好商场都能进”“签免责书即可免责”。
- “系统已全自动完成收款、分账、保险、客诉或实时定位”，除非逐项可现场演示并有生产证据。
- “30–50 组一定满员”“商户一定增收”“下一场一定复制到其他圈层”。
- “参与者数据双方共享 / 永久归合伙人”。

可替换为：

- “首场以 30–50 组为容量目标，以 T-14 的付费 Go 线决定是否举办。”
- “任何城市级或其他圈层合作，均在首场复盘后另行评估和签约。”
- “收益以实际收款、实际成本和协议口径结算，不设保本或最低收益。”
- “场地、活动属性和保险以书面确认结果为准。”

## 14. 制作 Figma 前仍需用户确认的商业决策

| 决策 | 为什么必须先定 | 推荐默认值 |
|---|---|---|
| 首场是售票、免费 + 履约金，还是品牌赞助制 | 决定需求证据、消费者责任、现金流、Go 线与合伙人报酬 | 优先测试真实付费；若免费，至少用可退履约金 / 二次确认约束到场 |
| 首场只接犬，还是犬猫 / 其他宠物 | 法规、场地、应激与防逃方案不同 | 首场先做犬只，其他宠物后续专项设计 |
| 体验活动还是计时 / 排名赛事 | 影响体育赛事与犬只比赛属性、保险和规则 | 首场不计时排名，以完成任务为主；仍向属地确认属性 |
| 合伙人是个人还是公司 / 个体工商户 | 影响合同、发票、劳动关系和责任承担 | 优先可签约开票的独立主体 |
| 城瘾的签约、收款、开票主体 | 消费者权益、退款和结算只能有清晰责任人 | 在任何招募和售票前公开唯一主体 |
| 合伙人是否需要现金垫付，上限多少 | 直接决定招募对象和法律 / 信任风险 | 首场不收费用；仅允许预算内可偿还垫款 |
| 报酬模式与金额 | 不能在 deck 模糊写“高额分成” | 里程碑交付费 + 绩效奖金，分成后置 |
| 票价与成本口径 | 决定 Go 线和真实 ROI | 取得本地报价后做 30 / 40 / 50 组三情景 |
| 谁负责本地招募、客服、收退款 | 决定工时、数据权限与消费者责任 | 合伙人运营、城瘾统一规则；收退款单一主体 |
| 影像与案例素材权 | 影响传播、肖像和合伙人作品使用 | 单场限定授权、参与者另行同意 |
| 下一场 / 其他圈层的优先权 | 避免被理解为自动城市独家 | 只给优先复审 / 洽谈权，无自动授权 |
| 用户给出的暂定 KPI 是否接受 | 决定续约与奖金 | 在招募前锁定并写入协议附件 |

### 来源质量总结

- 核心法规、监管边界和上海政策均来自 A1 / A2 官方原始页面，证据质量高。
- 可比活动主要来自政府 / 体育局的招募页和复盘，适合验证“存在这种形式”和组织要素，不适合验证商业回报。
- 当前最大数据空白不是行业规模，而是**城瘾自己的付费需求、报价、系统成熟度、事故 / 退款机制和伙伴交付成本**。这些必须由首场的证据室和预售形成，不能用外部宏观数据补齐。
