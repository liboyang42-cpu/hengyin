# OWN-C05-06 — 使用量未知与估算分离

结论：NO_CHANGE_SOURCE_REVIEW；交付：SOURCE_DELIVERED_UNVERIFIED；验证：NOT_RUN。

LlmClient.chat 既有返回类型为 String，不携带 provider usage。generate 的 tokenIn/tokenOut 只由 estimateSingle 字符长度估算，saveLog 明确注释所有非空计数均为估算；provider 失败或空包的 tokenOut=null，tokenEst 同为 null，输入估算仍保留。成功或明确输出拒绝只记录现有估算字段，不新建真实 usage/成本字段。缓存或模型未调用分支的零值表示未产生模型文本，不把 provider 未知分支写零。
