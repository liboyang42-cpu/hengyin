## 静态缺陷

NodeDTO已定义id/clientNodeKey，却没有unlockAfterNodeId。edit-detail返回CmsTopicNode上的既有unlockAfterNodeId；重建时saveNodes/compileChapterFlow按NodeDTO插新节点，新行无法从DTO复制这个服务端既有字段。两路径原先均没有编辑后恢复前置关系，因而含“节点12须先完成节点11”的主题在编辑重排后会把前置变成null。ApiPlayProgressController继续输出该字段，原pages/play读取它判前置完成，这不是废字段。

同服务复制主题的原实现已有二遍nodeIdMap翻译前置关系；RouteNodeMaps也已记录真实旧node.id到生成新id并拒绝重复。现story/route引用缺映射同样抛错回滚，说明这里应保真，不能按下标猜前置。
