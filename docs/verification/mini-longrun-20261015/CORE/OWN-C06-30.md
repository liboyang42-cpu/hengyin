## 真实生产路径及最小修复

ApiUmsMemberController.getBalanceStatistics（POST /balance/statistics，约193行）→ UmsMemberServiceImpl.getBalanceStatistics（约55行）→ UmsMemberBalanceDetailServiceImpl.getWeekBalanceIncome（约135行）→ UmsMemberBalanceDetailMapper.xml.selectWeekBalanceIncome。

原 SQL 用 DAYOFWEEK(CURDATE())-2 作为两处偏移。周一到六下界是当周周一，但周日 DAYOFWEEK=1，减负一天得到未来周一。例如2026-10-18周日查询窗口错误为10-19至10-26，而周一周界下本周应为10-12至10-19，已有当周收入被漏掉。

只将两处偏移同改为 WEEKDAY(CURDATE())，其余 SQL 逐处保持：member_id、change_type=1、del_flag=0、SUM、COALESCE及半开区间不变，不改变既定周一周界、财务方向或时区政策。
