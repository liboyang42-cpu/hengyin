仅play/index.js增加任务语义签名与采集上下文助手（原有效session参数、module activity/session、taskCode/inputType/prompt/核验及completionPolicy、node状态、submission快照、该node采集序列），扫码success/fail使用相同闸。未拿revision变化一律拒绝，允许同一任务的无关投影刷新；任务语义或状态变化才作废。相同node重新发起采集后旧回调也失效。没有改变相机授权/扫码格式/后端权限或UI。
