根因 C04-NPC-LOG-UNKNOWN-USAGE，SOURCE_FIX，SOURCE_DELIVERED_UNVERIFIED。
回归 NOT_RUN；未运行任何手动验证/编译/语法/diff-check。

实际源链：AiGatewayResult只提供traceId/text/model/safetyFlag，不提供provider token usage。NpcChatService.logEntry却无条件把tokenIn/tokenOut写0，provider成功/专用结果未知/错误路径都这样写，导出npc_chat_log时无法区别真实0与未知。该日志不是网关AiGenerationLog已有长度估算，不能凭两个0宣称无成本。

最小改动只把这两个未知字段设null，并注释能力边界。NpcChatLog现有字段Integer，NpcChatLogMapper原样绑定；base_schema_20260818.sql中npc_chat_log.token_in/token_out本来DEFAULT NULL可空，无DDL。未新增估算算法/真实计费/价格/字段，也不改变任何额度事实、日志留存或删除范围。

新增OWN_C04_12Test源码经真实NpcChatService编排两种gateway替身结果：成功以及专用provider未知，要求传给writeService的日志token均null，同时原user/message/reply、SUCCEEDED或PROCESSING行为不变。用例未运行，不拿mock断言冒充SQL插入通过；真实专用环境后续仍需读回null。
