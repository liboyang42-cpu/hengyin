SOURCE_DELIVERED_UNVERIFIED；NOT_RUN。未运行 Java/Maven/DB、lint、语法或其他验证。

sessionRules(session) 与 journeyRules(session,topic) 两个真实入口原先调用 NodeJourneySnapshot.journeyRules。该 helper 对缺 journeyRules 键及 present-null 均返回 null，两个入口于是选择实时主题规则。checkContext、recordMistake 及 vitals/结算数值实际消费这些入口；坏存储中的 null 会使作者后续 hp.enabled、伤害等配置穿透旧局。

仅在原两个入口区分 present journeyRules:null，复用“旅程数值规则不可用”拒绝；缺键继续原 fallback，合法最小版本对象（schemaVersion=1）继续原默认规则，非 null 错类型仍原样交 JourneyRules.parse/既有 JourneyRulesValidator，不引入新的类型规范或错误转换。未修改 NodeJourneySnapshot、JourneyRulesValidator 或其他消费者；整个快照解析失败的原 fallback 保持。

正常 freezeJourney 始终序列化规则对象，不会生成这里的 present-null。本项仅是坏/不完整冻结存储的防御隔离，不声称常态新建故障，也不把非对象类型称为已确认 live 回落触发。

OWN_C06_29Test 四个 NOT_RUN 方法分别对两个入口覆盖：缺键保留 live；present-null 拒绝且不查询 live；合法最小版本对象保留默认 checkEnabled=false、不吃 live=true；[] 非 null 错类型继续原 validator 的 IllegalArgumentException。mock 不证明真实持久化、事务或设备业务流程。
