# OWN-C05-15 — provider响应不可强转文本

SOURCE_DELIVERED_UNVERIFIED；NOT_RUN。

真实静态缺陷：post对content使用getString，非字符串JSON对象/数字等可被强转为文本，畸形HTTP成功包因此变成正常模型答案。现提取私有responseText，仅接受原choices数组/choice对象/message对象中的非空白String content；返回字符串原文，不将JSON字符串正文再次解析或更改。非String/null/空白/畸形结构抛异常。

调用位置仍在已发送HTTP之后：网关捕获时按原UNKNOWN保留额度，未新增退款/重试，也未放开新供应商响应协议。视觉正常返回的JSON文本字符串仍接受。专属回归直接执行实际parser，覆盖对象/数组/数字/布尔/null/空白及结构缺失，未启HTTP；本轮连该回归也不运行。无新依赖/API。
