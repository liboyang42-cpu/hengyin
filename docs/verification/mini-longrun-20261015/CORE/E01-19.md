# E01-19 显式取消主题点赞并发幂等

- 业务基线：`0d63043ad06775bc3dc52fb925620ef36d1081a7`。
- 关联：既有 EXTRA packet `PR16#6198507537`；不新增 bug ID。
- 根因：两个显式 `type=0` 请求均按当前 member/topic 读到旧行 `id=99` 后，DELETE 分别返回 1/0；原 Controller 将第二次 0 行删除误报为失败，违反既有显式 desired-state 幂等合同。
