# OWN-C05-16 — 空白密钥本地拒绝

SOURCE_DELIVERED_UNVERIFIED；NOT_RUN。

真实静态缺陷：requireReady原StringUtils.isEmpty仅拒null/空串，全空格/制表符密钥会通过本地检查后POST，再被网关按HTTP后UNKNOWN处理。现仅将null或trim后空串识别为无密钥，不修改有效密钥的原内容、默认URL、model、provider或价格；网关已有requireReady未发送补偿链直接复用。

专属回归源直接调用requireReady，覆盖null、空串、空格、控制空白和synthetic有效key，不起HTTP；本轮未执行。model缺失是否允许供应商默认并无统一既有契约，未增加必填规则或修改payload；该延伸不在本项已批准空白key修复中。
