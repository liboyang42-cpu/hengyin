# OWN-C05-08 — 补偿 worker 栅栏租约

结论：NO_CHANGE_SOURCE_REVIEW；交付：SOURCE_DELIVERED_UNVERIFIED；验证：NOT_RUN。

静态链：runDue 逐行处理并隔离失败；reconcile 在 REQUIRES_NEW 事务中 claim(candidate.id,candidate.fence,随机owner)，失败立即返回且不触Redis。SQL claim 同时要求原fence、可恢复状态、到期请求租约、到期/空旧owner、到期重试时刻，成功递增fence；同事务 selectById 读回新fence。complete/retry 均带 id+owner+该新fence+未过期claim_until，旧owner迟到不能完成或重排。
