NO_CHANGE_SOURCE_REVIEW；SOURCE_DELIVERED_UNVERIFIED；NOT_RUN。

静态追踪：FINISH只允许RUNNING并先closeStations再bumpSession(FINISHED)。玩家choice/submit/hint/reveal、商户verify/pause/resume各入口要求RUNNING；角色分配/确认和商户准备限定PREPARING/READY。已终态的后到新请求在入口拒绝；读取旧RUNNING快照的在途请求即使先写子表，最终updateSessionCas以revision/fromStatus及status not in FINISHED/CANCELLED拒绝，抛异常导致原命令整体回滚。FINISH与另一命令竞争时，仅符合该次revision的更新能提交；若FINISH失败则其closeStations也回滚，不形成假终态。旧requestId重放只读原回执，不再次dispatch。若分支提前返回已有submission/outcome，没有追加新终态完成事实。

结论：本项指定的终态后追加节点完成/改变已结束结果未找到新增可修缺口，不改变终态定义或取消/恢复玩法。后续真实MySQL应控制FINISH与player/merchant子表写交错，独立读回最终session/station/outcome/receipt，当前仅源码审查，所有运行验证延期。
