# OWN-C04-07 — 已有语音回执先读

结论 NO_CHANGE_SOURCE_REVIEW；根切片 C04-VOICE-REPLAY-BEFORE-ASR。
SOURCE_DELIVERED_UNVERIFIED；新增回归源码 NOT_RUN，无手动验证。
静态源码基线4a943501，本项不修改生产源或既有feature开关。

ApiAiNpcController.voiceChat在现有shopChatOn门禁后取登录身份，立即调用storedShopRequest(requestId,userId,nodeId)；只要非null就success(stored)返回，顺序先于ASR.available、文件读取/格式检测、当前资格判断与transcribe。因此已有PROCESSING、SUCCEEDED以及失败/拒绝/删除墓碑均不重转写、不重进chatWithShop。存储读取不可用也返回非null的REQUEST_STATE_UNAVAILABLE，不能“查失败即重做”。

NpcChatService.storedShopRequest验证UUID/本人/node范围，并比较存储sessionId==-nodeId，调用writeService当前持久读；不重新生成或合成语音。现有过期未知回执保持原ID且不可重试。

新OWN_C04_07Test源码锁定controller在既有PROCESSING/SUCCEEDED回执存在时即使file=null也原样返回，不触达ASR或chatWithShop，覆盖原controller回归未明确锁定的回放优先顺序。它只测试编排边界，尚未运行，不宣称真实ASR通过。

本项触发明确是“已有回执”。两个请求都在首次ASR之前且没有任何回执的并发，不在已有幂等能力内；新增ASR前持久占位/收费重试合同需另行范围，不能声称现代码保证同ID永远只转写一次。门禁关闭后的旧回执恢复是否放行也涉及现有开关裁决，本项不改变。
