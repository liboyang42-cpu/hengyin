# OWN-C05-10 — 额度展示计数超32位

SOURCE_DELIVERED_UNVERIFIED；NOT_RUN。

静态缺陷：remainingQuota 将 Number.intValue 截断或 Integer.parseInt 失败回0。合法字符串2147483648或Number4294967296因此显示满额，而预占Lua接受更大的合法整数计数。显示值不能据此代表可用次数。

改用long读取合法计数及long减法；负值先饱和0，最终剩余以原int上限返回。没有改变预占/退款脚本、分池、上限、日期或收费；Redis不可用及非法字符串既有展示降级保持。专属回归源覆盖两种溢出向量、Long.MAX_VALUE、正常计数、0和缺失；未执行任何验证。
