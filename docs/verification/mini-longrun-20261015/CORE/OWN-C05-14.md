# OWN-C05-14 — reserved原receipt事实

NO_CHANGE_SOURCE_REVIEW；SOURCE_DELIVERED_UNVERIFIED；NOT_RUN。

reserved(receipt,used)只GET传入的原receipt，不读取当前counter:generation。缺失转空串，找不到合法非空generation分隔位置即抛异常；数字suffix必须与已收到used的字符串完全匹配。成功时仅将该receipt中generation与used写recordReserved；SQL限定对应receipt、PREPARED、无owner及有效请求租约。写入失败立即异常；consumeQuota调用者捕获该异常并按原key/receipt登记补偿，不继续生成模型。

不会通过当前计数/代次补造旧预占事实，也不会在凭据缺失时当成功。无需新增generation来源或DDL。used由预占Lua返回正整数，入口不是外部HTTP DTO；不为不可达任意伪造Java参数新增政策。已有恢复/预占回归源码可复用，未执行、不复制。下一项15严格provider响应形状。
