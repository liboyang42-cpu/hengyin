- TRENDING有效score游标分支为 `(score < cursorScore OR (score = cursorScore AND id < cursor))`，括号限定该OR，仅影响排序窗口，不能越过外层权限AND。其ORDER BY恰为score DESC,id DESC。其余分支id<cursor配id DESC。

## 指定触发的结论

1. 第一页后帖子转PRIVATE或DELETED，再带旧游标读下一页：下一次selectFeed重新执行当前父行生命周期与可见性条件；旧游标只是额外收窄条件，不是授权回执。非作者旧公开资格不能由游标延续。
2. 第一页后退群/取消关注/发生拉黑：成员/关注/屏蔽均在同一父行查询的EXISTS/NOT EXISTS中重新求值；游标参数没有跳过这些条件的路径。
3. 伪造TRENDING游标值/漏传cursorScore：合法双游标走既有复合排序；缺score沿现有id游标回退。即使窗口选择不同，外层权限过滤仍保留。未更改缺score兼容协议。
4. 分页期间热度改变可能使同一行移动到不同窗口；现有协议不是跨请求冻结排行榜。本项不虚构快照分页承诺、不改变排名/游标字段或为此引入新状态。
