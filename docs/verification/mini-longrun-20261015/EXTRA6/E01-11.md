4. `chengyinhub-admin/sql/migration_club_role_event_ops_20260823.sql:56-74` 定义waitlist.id为BIGINT NOT NULL AUTO_INCREMENT PRIMARY KEY。SQL直接投影或MIN，非业务可选字段，不会因某业务target缺失就丢失scanId。
