## 静态反例和最小修改

`audio-session.js` 的 register 原本每次覆盖 Map entry：register(ctx) → interruption begin（wasPlaying/interrupted=true，ctx被pause）→ 重复register(ctx)（重置两个标志为false）→ interruption end 无法恢复。这不同于注销后重注册：没有 unregister 就仍是同一个活跃 context，其恢复账应保留。pauseAll→重复register→resumeAll 同样会丢 wasPlaying。
