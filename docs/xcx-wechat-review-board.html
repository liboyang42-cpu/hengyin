审核前缺口看板

口径：微信审核员点得到的按钮必须真能用。不能再留「即将开放 / 暂未接入 / 还没做好」。每条只有两条路：做完或从界面拿掉。原生 App 登录支付不在本表。

提审红线：占位入口、空壳路由、点了只 toast 的图标，都会被当成「功能不可用」。历史深链壳如果审核员扫到旧码，也必须跳到真页，不能白屏。

包体（源码字节，压缩后才是微信真值）

你给的限：主包 ≤ 2MB，单个分包 ≤ 2MB，合计 ≤ 20MB。仓库门禁里合计写成了 30MB，提审按你这条 20MB 来。下面是未压缩源码。主包源码已经 3415KB，过 2MB；编译压缩后通常会掉一截，但余量薄，发版必须用开发者工具「代码质量 / 包体积」回读，不能拿源码当真。
