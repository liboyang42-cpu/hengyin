# 小程序核销成长奖励事实与恢复

小程序商家核销、章节核销及领队核销使用服务端报名核验事实发放到店成长奖励，客户端不能仅凭任务编码领取。同一报名的同一任务跨日重试不重复奖励。

核销事务保存唯一报名待办及当时任务快照；发奖失败后由定时任务恢复，不依赖二维码有效期、章节候选或客户端重扫。奖励与待办完成同事务；核销入队失败则原核销事务回滚。空快照保持为空，历史奖励不重发，没有待办的历史核销不自动追授。
