# 流 5 · IM 消息中心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给 IM 加三 tab(私信/俱乐部/系统)、群聊主题上下文、富消息卡(位置/路线)、免打扰;顺带修一个既有 P0(对方气泡对比度 1.10:1)与一个既有安全洞(用户可发伪造官方卡片)。

**Tech Stack:** Java 8 + Spring Boot + MyBatis(RuoYi 骨架)· JUnit 5 + Mockito · 微信小程序原生(wxml/wxss/js)· fastjson2

**Spec:** `docs/superpowers/specs/2026-07-16-im-center-design.md`

## Global Constraints

- **Java 8 API only**(`pom.xml:19` `<java.version>1.8</java.version>`)。本机 JDK21 + plugin 3.1 无 `--release`,用 Java 9+ API 本地能过、CI 必挂。禁用 `List.of` / `Map.of` / `var` / `Optional.isEmpty` / `String.isBlank`。用 `Arrays.asList` / `new HashSet<>(Arrays.asList(...))`。
- **JSON 库 = `com.alibaba.fastjson2`**(`JSON.parseObject` / `JSONObject`)。全仓既有用法见 `NpcEventService.java:11`。
- **零迁移**:本计划不含任何 `chengyinhub-admin/sql/` 改动。`im_conversation_member.muted` 已在库(`migration_im.sql:32`)。
- **无新增 `@Component("xxxTask")`**,故无需 `insert into sys_job` 注册 SQL。
- **前端新样式只用 `--cy-color-*` 语义 token**(DS 第 5 行:新代码禁止硬编码色值与旧名)。不动 im 页既有旧 alias,除非本计划明确列出。
- **IM 两页 = 深色**(未挂 `theme-light`;`tokens.wxss:18` `page{}` 即深色基础层)。所有配色按深色值验算。
- **DS 字阶下限 micro 20rpx**;间距 8rpx 网格;圆角 `sm16/md24/lg32/pill999`;**暗底阴影 `none`**。
- **测试每条带负控**:注入 → 红 → 撤销 → 绿。memory `feedback-false-green-test-patterns` 记载一天栽 4 次假绿。
- **跑单个测试类必须加 `-Dsurefire.failIfNoSpecifiedTests=false`**(T1 实测发现):`chengyinhub-common` 无 test 目录,`-Dtest=X` 配 surefire 默认 `failIfNoSpecifiedTests=true` → reactor 在走到 `chengyinhub-admin` 之前就 `BUILD FAILURE`,报 `No tests matching pattern "X" were executed!`。这是**既有仓库特性、与本次改动无关**(已 `git stash` 复现于干净树)。**只加命令行参数,不改 `pom.xml`、不碰 CI。**
- **Service 层错误约定**(`IImService` 类注释):业务校验失败抛 `RuntimeException`(中文提示),控制器 try/catch 转 `AjaxResult.error`。

3. skill `subagent-driven-development` 明令:*Never dispatch multiple implementation subagents in parallel (conflicts)*。

  decorate(list) {
    let last = 0;
    const that = this;
    const decorated = list.map(function (m) {
      const t = m.createTime ? new Date(String(m.createTime).replace(/-/g, '/')).getTime() : 0;
      let divider = '';
      if (!last || (t - last) > 5 * 60 * 1000) divider = fmtAbs(t);
      last = t;
      let card = null;
      if (m.msgType == 3) {
        try { card = JSON.parse(m.extraJson || '{}'); } catch (e) { card = {}; }
        if (!card.cardType) card.cardType = 'generic';
        if (card.cardType === 'generic' && !card.title) card.title = m.content || '通知';
      }
      return Object.assign({}, m, { timeDivider: divider, card: card });
    });
    that.fetchTopics(decorated);
    return decorated;
  },

  // route 卡现拉(spec 决策 8:永远最新)。去重 + 页面级缓存;
  // 一屏 30 条里路线卡通常 0-2 张,不值得为此加批量端点。
  fetchTopics(list) {
    const that = this;
    const cache = this.data.topicCache;
    const ids = [];
    list.forEach(function (m) {
      // route 与 signup 同构,共用现拉
      if (m.card && (m.card.cardType === 'route' || m.card.cardType === 'signup') && m.card.topicId) {
        const id = m.card.topicId;
        if (!cache[id] && ids.indexOf(id) < 0) ids.push(id);
      }
    });
    if (!ids.length) return;
    ids.forEach(function (id) {
      app.sendRequest({
        url: '/api/topic/info-to-user', method: 'POST', hideLoading: true,
        data: { id: id },
        success(res) {
          const d = (res && res.code == 200) ? res.data : null;
          // 拉不到/已下架 → 记 null,渲染层出降级态「该路线已下架」
          that.setData({ ['topicCache.' + id]: d || null });
        },
        fail() { that.setData({ ['topicCache.' + id]: null }); },
      });
    });
  },
