Template adoption** `POST /api/template/topic-template/use` (form): `id`, `scope?` (`MERCHANT`), `bindingIntent?`, `targetCityCode?`, `sourceContentRevisionId?`, **`requestId?`** (`[A-Za-z0-9._:-]{8,64}`).
