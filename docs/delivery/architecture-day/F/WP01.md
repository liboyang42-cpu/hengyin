## 增量规则、精确例外和成本

- 新增跨模块 mapper/internal 包显式 import 为违规，包括可解析 static member/嵌套类型。同 owner Mapper 正常，普通非私有包引用本身正常；这不证明其是获准业务 API。引用身份包括源文件、目标、kind、具体 owner 和规范 import SHA256，旧 Controller 的例外不能给新 Controller 使用。
- 图由直接子 POM 模块声明边及已解析显式 import 组成。新/扩大 SCC 为违规并附新增边 witness；Maven 自依赖也计环。旧 SCC 不重复报，缩小/拆分允许；未解析的依赖不被算成“已证明没有环”。
- 固定 527：53 条精确存量私有 import、10 条模块边、无已解析 SCC。每次从相同 Git blobs 精确再生，拒绝添加例外或候选 baseline 篡改。相对暂停草稿，只因不再强行索引 Unicode 文件移除 common.utils.sql 的包索引；53 条例外和 10 条边逐项不变，没有扩大 baseline。
- 扫描 O(源码字节数＋import 数)，图比较 O(V×(V＋E))，当前 V=6；内存 O(源码字节数＋引用数)。不执行 Maven、服务或外部业务动作。
