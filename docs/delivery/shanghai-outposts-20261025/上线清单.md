# 上海官方地点挑战 · 公开发布上线清单（2026-10-25）

目标：公开发布后约 100 位测试者用真机在 5 个上海地点完整玩一遍：地图看点位 → 卡片看照片 / 介绍 / 网上怎么说 / 玩家评价 → 到场后地图上弹出取景卡拍照 → 整屏答题 → 获得「点亮一隅」地点勋章（徽章墙）→ 写评价 / 投一张换一张。

每一步涉及生产的操作都要业主逐项明确授权；本清单只列顺序和核对点。

## 0. 已在测试环境（8132 / cy_roam11_dev）验证

- 地图卡展开、照片左右滑、小红书复制地点名、玩家评价发布与回显
- 未到达只在卡上提示距离；到达后地图取景卡（cy-proto-cam）弹出，✕ 回到卡片
- 真实照片上传 → 服务端核验照片归属 → 答题 → 发勋章，库里 reward_log 记照片地址与答案
- 重复完成只提示「已经收藏过」，不重复发勋章；徽章墙按 badgeCode 定位到这一枚
- 公开引述 6 条逐字核对原文（`public-quotes.json`）

## 2. 生产顺序（每步单独授权）

1. 合并：分支经 PR 合入 master（业主合并），CI 全绿。
2. 生产迁移（chengyin-db-migrate 只读预检 → 业主确认 → 执行 → 回读）：
   - `migration_20261012_app_media_asset.sql`（若生产尚无该表；测试库缺它时上传全部失败）
   - `migration_20261024_official_roam_challenges.sql`
   - `migration_20261025_official_poi_quotes.sql`
3. 部署后端 jar（业主操作），回读 `/api/city/nodes/{id}` 含 quotesJson / templateDesc / photoRequired。
4. 数据：用后台「官方据点 · 地点与游戏」逐个录入 5 个地点（照片、拍照任务、题目、公开引述），保存后审核通过；不用 SQL 绕过审核。勋章在审核通过时自动生成（ROAM_POI_<地点ID>）。
5. 小程序：上传版本 → 提交微信审核 → 发布。隐私指引需含位置、相机、相册用途。
6. 发布后用一个真实账号在一个地点走完整流程，再通知测试者。
