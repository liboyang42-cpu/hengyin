状态切换

相对现状改了什么

  • 输入从底部聊天式输入条挪到页面正中的大输入框，带示例占位、字数、清空——一眼看出「在这里配置」。
  • 灵感 chip 点一下填入完整的一句话（保留现有 3 条，新增 2 条）。
  • 新增可折叠「补充条件」：城市 / 时长 / 人数，拼进同一段描述发给 AI，不改接口。
  • 生成中：三段进度（理解需求→规划路线→编写玩法）+ 骨架屏，可取消，描述保留。
  • 结果：标题、简介、预计时长、票价、节点都能就地改；节点可上移/下移/删除/添加；底栏 重新生成 / 保存草稿 / 进入专业配置。
  • 失败：替换「这次没能继续 / AI 响应格式异常」的死胡同，改成友好错误卡，「重试」直接用保留的描述再发一次。
  • 「重新生成」「确认地点」「选择城市」走底部弹层；有弹层时导航栏返回先关弹层（G-2）。
