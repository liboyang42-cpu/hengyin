现状（p115）

  • 迷雾没法关；搜「海星市场」搜不到（根因 E-1：腾讯地图 Key 未配）。
  • 读数卡目标行会出现「该区域暂未开放 · 发现附近真实店」。
  • 地图上的活动、组队只在开始前的入口地图有，运行态看不到。

这版改了什么

  • 设置里新增「迷雾」开关（更多 → 设置，或点左上「迷雾」小标签）。关掉后迷雾层淡出。
  • 地图上的活动、组队图钉盖在迷雾上面，所有人都能看到。底部用横滑卡：头像堆、队名 / 活动名、主题、距离、人数进度、加入 / 查看。滑到哪张，对应图钉高亮、地图平移过去；点图钉，卡片滚到它。
  • 搜索不经过迷雾：迷雾开着也能搜到迷雾里的地点（结果标「未点亮」），结果卡有「导航」（wx.openLocation）。
  • 删掉「暂未开放」：节点空态改为「附近还没有漫游节点 · 发现附近真实店」。
  • 其余（白色搜索框、读数卡、三键、抽屉、设置各行）照现有页面还原。
