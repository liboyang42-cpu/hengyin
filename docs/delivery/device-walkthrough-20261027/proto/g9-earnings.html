相对现状改了什么

  • 玩家「账户收益」(assetcenter/earnings) 与商家「结算」(merchant/ledger) + 「我的资产」合成一个页面，统一叫「账户收益」；结构一样，只换颜色（玩家深色 / 商家浅色）。
  • 顶部余额从 0 滚动到实际金额（easeInOutCubic，1.2s，慢-快-慢）；切主题、切数据、重播都会重放。
  • 操作只留两颗圆按钮：提现、明细。原「提现记录」收进「我的资产」行；玩家「邀请记录」同样收进去。
  • 「本月收入明细」预览 3 条，点标题或任一行打开单月弹窗：‹ › 每次只移一个月，按日分组，每行写收入来源。玩家来源：主题售卖 / 邀请奖励 / 活动分润；商家来源：门票分成 / 承接活动 / 核销计酬 / 合作分润。
  • 删除「俱乐部计酬」区块（club-direct-ledger），这类收入作为「核销计酬」来源进明细。
  • 「我的资产」：可提现 / 待结算 / 已结算三行；下面「结算」批次列表（商家原「对公结算」），点批次开小详情（净额、打款凭证复制、对账单、打款进度）。
  • 空态：余额滚到 0.00，各行显示 ¥0.00 而不是「—」（按 0.3）；去掉原大插画「还没有收益 去发布路线」，改成卡内一行空态。
  • 弹层打开时点导航栏返回 = 先关弹层（G-2）。
