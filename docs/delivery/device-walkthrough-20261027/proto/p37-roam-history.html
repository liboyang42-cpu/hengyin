这版改了什么

  • 改成全屏页面（G-1）：导航栏返回、大标题，滚动后导航栏出标题。页面底色用 surface #0A0A0B，卡片用 #141416，地图用深灰样式，不是纯黑。
  • 按月分组（参考 NRC 历史）：每月一个头，带当月 距离 / 次数 / 时长 合计。
  • 每条记录是一张轨迹地图卡：地图占卡片主体（街道 / 水系 / 公园 + 绿色轨迹，起点绿点、终点白点），下面日期、标题、公里 / 用时 / 探店 / 探索度，底行邮票和勋章。
  • 点卡片进详情：大地图 + NRC 斜体大数字 + 六格数据 + 勋章 + 邮票 + 分享（接 P-36 通用分享页）。
  • 筛选：全部 / 本月 / 上月 / 有勋章 / 有邮票。汇总行、三个工具、空态文案沿用现有组件。
