### #128 BL-85 商家工作台开通前置检查（只读）

分支：`claude/bl-85-merchant-prereq`

1. 用资料不全的店主账号进入商家工作台：出现「开通前置检查」，只列未完成项（比如店铺封面、品牌故事），点「去完善」进入店铺装修。
2. 「商家账号启用」这类没有去处的项：不显示「去完善」，点了没反应。
3. 资料全部完成（canContinue=true）后回到工作台：整块不显示。
4. 核销员、财务等没有资料写权限的岗位：不发这个请求，也不显示区块。
5. 断网或接口报错：区块不显示，不弹错误，工作台其他部分照常。
6. 入驻审核中、未通过：只显示原来的状态卡，不显示这个区块。

### #130 BL-87 系统消息审核结果详情（回读审核记录）

分支：`claude/bl-87-audit-detail`

1. 用提交过内容、被审核（通过或未通过）的账号，打开系统消息里的审核卡片：半屏先显示「正在读取审核记录…」，然后显示「当前状态：审核未通过」和时间线（提交审核、审核未通过：原因）。
2. 举报人收到的「举报已处理」卡片（审核任务的提交人不是自己）：显示「审核记录没有加载 / 无权查看该审批记录」，**没有**重试按钮；卡片原有的 4 行仍然完整显示。

5. 加载中关闭半屏再打开另一张卡片：不会出现上一张卡片的结果。

### #132 BL-89 到访安全感受评价（已核销商家节点）

分支：`claude/bl-89-safety-rating`

1. 商家节点没核销时，主按钮按原样显示「扫描门店码 / 拍摄到店凭证 / 出示核销码 / 结果待确认」，**不会**同时出现「已核销」或「评价」。
2. 被商家核销后，主按钮仍显示「已核销」，左边多一个「评价」按钮。
3. 点「评价」：先显示「正在读取评价选项…」，然后出现安心 / 一般 / 不安心三个选项。没选档位或没填原因时，提交按钮不可点。
4. 选「安心」、填原因、提交：弹出「评价已提交」，显示受理编号和评价周期。
5. 同一个月对同一家再评一次：半屏里显示后端文案「本自然月已评价该商家，请勿重复提交」，不显示成功。
6. 没有真实核销记录：显示「仅真实核销到店记录可提交安全感评分」。
7. 断网时打开或提交：显示网络错误，可以重试，已填内容还在。
