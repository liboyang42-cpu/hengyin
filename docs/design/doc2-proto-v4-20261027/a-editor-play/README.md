## 10-28 难度与属性改内联

业主 10-28 晚的意见：规则难度和属性设置要调整。规则难度不要「勾选」样式（选项后面一个勾），换一种更好看的选法；属性不要左右两栏；添加用半屏或就地编辑，弹窗太多了。

这一轮只改原型 A 的编辑器，规则是**从任何一张半屏出发，最多再开一层**。页面外壳、浅色商家主题、零英文（只有「d20」）、不要副标签、条件和效果写成句子、橙色「改动」标记（点开看前后）、联动面板，都照已认可的版本。

**1. 规则难度：三张大卡（`e-d20`）**
- 「规则难度 · 标准 ›」那一行和它的下一层（勾选列表）都删掉。d20 半屏第一层直接放一排三张大卡：轻松 / 标准 / 硬核。
- 每张卡：一颗 d20（内联 SVG，越难线越粗）、粗体名字、三颗点（亮 1 / 2 / 3 颗）。没有说明文字。
- 选中的那张填满强调色（`--cy-color-action-primary-bg`）、微微浮起；其余是描边卡。点一下有回弹（`--cy-ease-spring`、`--cy-motion-expand` / `--cy-motion-sheet-in`）；系统设了「减少动态效果」时不回弹。
- 三档的数字（8/11/14、10/13/16、12/15/18 等）仍只在底下，不显示。主题详情那一行「4 项属性 · 标准」跟着变。

**2. 属性：就地展开 + 预设药丸（`e-d20`）**
- 左类型 / 右设置的两栏下一层（`e-d20-add`）整个删掉。
- 每行：色点、名字、「开局 / 最大」（观察 **2** / 5）。点一行就在下面展开：最小值 / 最大值 / 开局值三个步进器（互相挡住：最小值到不了最大值，开局值跟着收进范围），改了立刻生效；最下面红色「删除」。再点一下或点另一行就收起，一次只开一行。
- 列表下面一排预设药丸（观察、胆量、体魄、灵感、敏捷、魅力、运气，只列还没加的）+「＋ 自定义」。点预设立刻加上（带它的预设范围），并自动展开；「自定义」原地变成输入框 +「添加」，重名写一句「已有同名的属性。」。类型带来的颜色、图标、显示方式照旧在底下。满 6 项时这一排不出现。
- 左滑删除、「编辑」拖动排序照旧。

**3. 少弹层（其余各屏）**
- 进度钟、特质（`e-d20-more`）：第三层表单删掉。点一行就地展开（进度钟：名称 / 坏事逼近·事情进展 / 4·6·8 格；特质：开局自带开关 / 说明 / 移除）；「添加进度钟」原地变输入框；特质下面一排预设药丸，点一下就加上。
- 线索与物品（`e-keys`）：下一层删掉。点一行就地改名，被用到时下面列出「用在」，删除变灰；「添加线索 / 物品 / 标签」原地变输入框（种类就是那一组）。
- 初始状态（`e-init-add`）：搜索 + 多选这一层保留（线索、物品会很多，要搜索）；「新建…」就地展开（分段 + 名称 + 新建），第三层删掉。
- 到达与引导（`e-quest`）：扫码 / 答题 / 拍照三个下一层删掉，开关就在行里，打开的那一行下面直接是要填的；备用节点就地多选。到达地点保留下一层（地点多、要搜索）。
- 下一站（`e-route`）：「一种结果」这一层和「去往」「数量」「新建」「一组条件」都不再单开。每种结果点一下就地展开：去往（就地勾选）、条件、效果；点一句就地展开：肯定 / 否定、短名单（属性、进度钟、特质、数值）用分段换名字、至少 / 至多 / 正好、数量步进器、红色「删除」；一组条件在灰盒子里再列一层句子。只有「添加条件 / 效果」还开一层：种类一列，点一种就地展开名字（可搜索，写名字就出现「新建「…」」）；名单长的「换一个名字」也是这一层。
- 玩法模板（`e-temp`）：加上属性、幸运加分就地展开勾选（不再叠半屏）；情境加值、代价点一句就地展开（数量、固定加值 / 加上属性值、删除）。只有「添加加值 / 添加代价」叠一张半屏（页面上的第一层），「加多少」第三层删掉。
- 消耗与效果（`e-after`）：「之后」就地两项勾选；「添加消耗」就地一排药丸（数值只有几个，「新建数值」原地变输入框）；「添加效果 / 条件」同下一站，开一层。
- 编辑数值（`e-value`）、节点编辑（`e-node`）、发布确认（`e-publish`）本来就只有一层，没动。

## 10-28 专业配置重做

业主 10-28 下午的意见：专业配置的其它几页界面还不对；`clue.ledger_half` 这类东西不该出现，作者要配置的东西必须简单、不带英文；界面问题很大，其余没问题。

这一轮只动下面 9 个屏（和它们新加的下一层），全部照已认可的「d20 与角色设定」半屏来做：卡片叠放（上一张缩小变暗）、导航栏「‹ 上一层 / 标题 / 完成或添加（没填好是灰的）」、分组列表（左名称、中间值、右 ›）、开关、步进器（上下限由控件挡住）、分段控件、左滑删除 + 底部红色删除、「编辑」排序。d20 那一组、可玩时段、开局前准备、游玩页都没动。页面外壳、导航栏、token、浅色商家主题照 master。

**规则落地**
- 手机里零英文、零键名：除了「d20」，渲染出来的文字（含输入框的值和占位）里没有任何拉丁字母。下面「检查结果」是每个屏、每个状态跑出来的结果。
- 选，不填：每个选择都是点一行，推进下一层的勾选列表（能新建时有搜索框和第一行「新建…」）。没有下拉框、没有「▾」、没有原生选择器、没有要手打的代码、没有逗号分隔。
- 条件和效果写成一句话（照 Apple「家庭」自动化）：「已获得线索 · 半张货单」「属性 · 观察 至少 3」「进度钟 · 巡夜人警觉 +1」。添加时一步一步：先选种类 → 再选名字 → 最后数量（步进器）。两条以上条件出现「全部满足 / 任一满足」分段控件；嵌套只在需要时用「一组条件」下钻一层，不画缩进树。
- 数据结构不变：键名（clue.* / tag.* / counter.*）、op（HAS_TAG、TICK_CLOCK…）都还在底下，由选择生成，只是作者看不到。对应关系写在每屏右栏「接口 / 字段」。

## 用词表

一个意思只用一个词。

| 用这个 | 不用 | 说明 |
|---|---|---|
| 主题 | 剧本、玩法（指整个主题时） | 作者做的一整个东西 |
| 节点 | 站、站点、某站 | 新文案一律用「节点」；master 原有的「第 1 站」「我已到达此站」「下一站」没改 |
| 玩家 | 用户、你（作者侧） | 作者侧说「玩家」；玩家侧直接说「你」 |
| 属性 | 角色属性、技能值 | 观察、胆量、体魄…… |
| 检定 | 骰子检定、判定 | 开关叫「d20 检定」 |
| 通过 / 未通过 | 过线、过了、没过、没通过 | 检定和审核结果 |
| 开局值 | 初始值、开局 N（作者表单里） | 列表摘要仍写「0–5 · 开局 2」 |
| 最小值 / 最大值 | 下限 / 上限 | 只在新表单里；master 的「上限（主题设置）」没改 |
| 进度钟、特质、动量、魔鬼交易 | — | 沿用业主定的叫法 |
| 管理员 / 商家 / 帖文 | — | 本原型没有用到，保持项目原词 |

**写法规则：** 标签是名词，不带句末标点；按钮是动词（添加 / 完成 / 删除 / 取消 / 重试 / 提交）；脚注只写一句；不出现键名、字段名、英文缩写、版本号和系统解释；出错时说发生了什么和怎么办，不责怪人；范围写「0–8」，时段写「20:00–06:00」（短横线是 en dash）。原型里括号中的灰字（如「（d20 检定关闭：这一块不出现）」）是给评审看的状态说明，不是界面文案。
