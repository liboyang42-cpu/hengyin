# 漫游入口地图化与城市定向报名组队：实施落地施工文档

> 日期：2026-09-21
> 设计基线：Figma《漫游入口优化》
> 实施分支：`feat/roam-entry-map-20260921`
> 边界：只改开始漫游之前；现有开场、迷雾、轨迹、打卡、暂停、结束、结算不重画

## 1. 最终产品链路

```text
底部「漫游」
  → 真实地图浏览态 entry-map（不创建漫游会话、不记录轨迹、不自动请求定位）
     ├─ 搜索活动或地点
     ├─ 查看活动/城市定向图片点位
     ├─ 查看同一活动的公开招募队伍
     ├─ 图层：活动、招募队伍显示/隐藏
     ├─ 图片打卡入口
     └─ 「开始漫游」→ 独立透明玻璃弹窗
                         → 用户确认
                         → 原有登录/恢复/定位链
                         → opening → map → arrive/finish

活动图片卡/点位
  → 透明玻璃活动半屏
     ├─ 绿色「先报名」
     │    → 黑色主题详情页
     │       → 选择场次并报名/支付
     ├─ 未报名：队伍卡提示「报名后申请」，进入附近队伍页后先去报名
     └─ 已持票：进入附近队伍现有申请半屏；也可从主题现有入口发起组队
```

## 2. 已施工内容

### 2.1 小程序入口地图

文件：

- `chengyinhub-xcx/pages/roam/index.js`
- `chengyinhub-xcx/pages/roam/index.wxml`
- `chengyinhub-xcx/pages/roam/index.wxss`
- `chengyinhub-xcx/utils/roam-entry-map.js`

完成项：

1. 默认 `screen` 从旧 `intro` 改为独立 `entry-map`。
2. `entry-map` 使用现有 `free-map + MAP_STYLE`，不是图片假地图，也未引入第二套地图 SDK。
3. 页面首次进入只用现有默认中心读取附近内容，不调用 `wx.getLocation`；只有用户点定位或确认开始漫游才请求定位。
4. 活动/主题使用 `GET /api/roam/entry/nearby`。
5. 公开招募队伍使用 `GET /api/team/nearby`。
6. 两层点位可同时显示，不再把“活动”和“队伍”设计成互斥模式。
7. 底部活动列表使用真实封面图片；地图点位复用已有活动/主题与队伍 marker，避免网络图片 marker 的真机兼容问题。
8. 地图拖动结束后 600ms 刷新附近内容，并以序号丢弃旧响应，避免快速拖图时旧结果覆盖新中心。
9. 顶部复用现有 `cy-map-address-search`，候选来自当前地图真实活动/主题数据。
10. 底部自定义 tabBar 只在 `entry-map` 出现；正式漫游仍保持沉浸态。

### 2.2 活动半屏与报名

活动半屏显示：

- 活动/主题真实封面；
- 城市定向/自由探索类型；
- 名称、距离、地址；
- 当前主题/活动下正在公开招募的队伍；
- 图片打卡入口；
- 绿色「先报名」。

报名跳转规则：

1. 点位有 `topicId`：进入 `/pages/topic/index/index?id={topicId}`；
2. 主题点位本身：用主题 `id` 作为 `topicId`；
3. 只有旧后端响应缺 `topicId` 时，才降级到 `/pages/activity/detail/index?id={activityId}`，避免按钮无响应。

绿色按钮不写新色值，使用现有玩家弹层 token：

```css
background: var(--cy-comp-sheet-player-success); /* #22C55E */
```

### 2.3 透明玻璃弹窗

入口活动、图层、自由漫游三类半屏统一复用漫游页既有 `psheet` 玻璃壳，不另起一套弹层组件。入口专用动效参考 Neighborhoods 地图：地图留在原位，半屏从底部短距离抬升并轻微回弹，350ms 落稳；减弱动态效果开启时沿用页面统一的 1ms 终态。该壳已使用：

```css
background: var(--cy-comp-sheet-role-glass);
backdrop-filter: blur(var(--cy-comp-sheet-blur));
-webkit-backdrop-filter: blur(var(--cy-comp-sheet-blur));
```

没有修改正式漫游使用的旧 `psheet`，因此开始漫游后的已有 UI 不受本轮玻璃化影响。

### 2.4 后端活动—主题关联

文件：

- `chengyinhub-system/src/main/resources/mapper/business/RoamHangoutMapper.xml`

`selectNearbyActivities` 新增只读字段并关联主题玩法：

```sql
a.topic_id as topicId,
t.product_type as productType
from cms_activity a
left join cms_topic t on t.id = a.topic_id and t.del_flag = 0
```

用途：地图活动的报名按钮可以确定性进入对应黑色主题详情页，同时不会把自由探索场次误标成城市定向。本轮没有建表、改表或数据回填，不需要数据库迁移。

## 4. “预制人生”类城市定向的手机发布闭环

要让下一次在手机专业主题配置里发布类似“预制人生”的城市定向，必须满足下面的数据闭环；它不是“预制人生专用页”。

### 4.1 主题配置

专业主题配置保存：

- 主题名、封面、简介；
- `productType=1`（城市定向）或 `productType=2`（自由探索）；
- 章节/节点及排序；
- 每个需要落地图的节点坐标；
- 游戏模组配置；
- 票务/场次需要的活动关联配置。

发布后满足：

- `cms_topic.status = 1`；
- `cms_topic.user_status = 1`；
- `cms_topic.del_flag = 0`；
- `cms_topic.is_template = 0`；
- 至少一个节点有合法经纬度。

满足这些条件，主题会通过 `selectNearbyTopics` 出现在漫游入口地图。

### 4.2 场次与报名

如果主题需要报名、付费、组队，还必须创建并发布 `cms_activity` 场次：

- `cms_activity.topic_id` 指向主题；
- `status = 1`；
- `publish_status = 1`；
- `del_flag = 0`；
- 未取消；
- 活动有坐标，或队伍可通过活动/主题节点取得集合坐标；
- 配置可售票档与报名时间。

只有主题没有活动时，可以在地图出现和进入详情，但不能完成“选择场次—付款—持票—组队”的完整闭环。

### 4.3 游戏模组

模组能否放进城市定向/预制人生，判断口径不是页面名称，而是模组是否满足：

1. 配置能由专业主题编辑器保存；
2. 发布快照能带入主题/章节/节点；
3. 玩家运行时能按节点读取；
4. 完成事实能回写统一进度；
5. 重进、断网、重复提交不会多发奖励；
6. 模组不依赖某一张专用页面的写死字段。

未满足以上六项的模组只能算编辑器展示或原型，不能宣称已支持城市定向发布。

## 5. 明确未纳入本轮：公开帖文地图图层

当前没有隐私安全的公共帖文地图读取接口，不能把含原始坐标的内容接口直接暴露给陌生用户。本轮只接入已有个人图片打卡/漫游记录入口，不伪造公共动态点位；以后若要上线公共图层，必须先由后端提供“仅公开且审核通过、服务端降精度或聚合、不返回原始坐标”的 bbox 分页接口，再接前端显示开关。

## 7. 验收用例

### 7.1 默认地图

- [ ] 点击底部“漫游”直接进入真实地图；
- [ ] 不再先看到旧“开始漫游/漫游护照”介绍页；
- [ ] 未点定位、未点开始漫游时不弹位置授权；
- [ ] 没有附近内容时仍显示真实地图，不出现假活动；
- [ ] 活动和队伍可以同时显示；
- [ ] 拖图后刷新新区域，旧响应不回盖。

### 7.2 活动与报名

- [ ] 活动卡以图片为主体；
- [ ] 点活动打开透明玻璃半屏；
- [ ] “先报名”为绿色；
- [ ] 点击进入黑色主题详情；
- [ ] 未报名队伍显示“报名后申请”；
- [ ] 已持票进入附近队伍现有半屏后可申请；
- [ ] 不出现“未报名也能发起/加入队伍”的旁路。

### 7.3 开始漫游

- [ ] 地图按钮先开独立玻璃弹窗；
- [ ] 关闭弹窗不会创建会话；
- [ ] 确认后复用原登录、恢复、定位、同意留痕；
- [ ] 开场动画、正式地图 HUD、迷雾、轨迹、结束和结算不变；
- [ ] 定位拒绝有明确错误，可再次操作。

### 7.4 视觉

- [ ] 活动/图层/漫游弹窗均为透明玻璃效果；
- [ ] 文本在地图亮底和暗底上均可读；
- [ ] 绿色只使用 `--cy-comp-sheet-player-success`；
- [ ] 44pt 触控热区、关闭入口和读屏标签齐全；
- [ ] iPhone 刘海/灵动岛与底部安全区不遮挡。
