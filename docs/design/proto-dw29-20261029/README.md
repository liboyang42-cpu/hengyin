## 主题勋章的生成规则(第二版)

第一版是「同一个珐琅底板 + 换徽记」,业主否了。第二版每枚是一张小插画,规则只定结构,画面按规则逐个主题画(设计或 AI 出图后人工修),不靠程序随机拼:

1. **外形 = 故事里的核心物件**:海上方舟 → 船舵(八根舵柄伸出边框)· 风味巡游 → 竹蒸笼 · 异常事务局 → 六边坐标牌(边框色差错位)· 时间污染 → 怀表 · 上海像一部旧电影 → 装饰艺术盾(外滩大楼的阶梯顶)· 高温末日逃生 → 水滴。外形不同,勋章墙上一眼就分得开。
2. **画面 = 封面场景拆三层**:远景(天色、时间)· 中景(城市地标、场地)· 前景主物件(勋章名说的那样东西,例如「老饕」= 三只小笼包和红漆筷)。
3. **破框**:每枚有一样东西伸出边框(热气和筷子、舵柄、表冠和表盘碎片、光芒、水珠、错位碎片),这是轮廓的辨识点。
4. **金属看风格**:怀旧人文 = 古铜 · 科幻异常 = 镀铬 · 生存逃脱 = 黑镍 · 美食 = 竹黄 · 其余 = 金;斜光从左上来,边框两层(外圈 + 反向斜面)+ 内槽。
5. **色板看封面**:沿用第一版从封面取的色相,每枚 4–5 档。
6. **背面**:同外形的拉丝金属,刻主题名、获得日期、编号;3D 查看时翻过来看。
7. **没点亮**:整枚灰阶压暗,外形不变。
8. **交付**:每枚一份 SVG(240 × 240 视框),导出 @3x PNG 给小程序;badge-3d 的 pin-spin 用正反两张图做转台。新主题上架时需要多交一张勋章图(见决定 38)。

参照的质量线:Apple Fitness 奖章、Nike Run Club 成就徽章 —— 立体金属边、分层插画、每枚轮廓不同。
