# 真机走查 10-29 · 原型 P-1 ～ P-4

只有原型,**没有任何小程序 / 后端代码改动**。业主确认下面的决定后,再由对应 lane 落代码。

打开 `index.html`。每个原型左栏是屏目录,中间是 390 宽手机(微信状态栏 + 胶囊),右栏是这一屏改了什么、复刻自 master 的哪个文件。顶部「显示改动」打开编号标注(橙色小圆点),鼠标停在右栏某条上,手机里对应的元素会描边。

## 怎么做的

- **复刻 master**:`tools/build-css.js` 把 master 的 WXSS(`style/tokens.wxss` 等全局样式、用到的组件、各页面样式)原样转成 CSS(rpx × 0.52 = 390 宽下的 px,页面样式按页根类加前缀),HTML 用和 WXML 相同的结构与类名,所以字号、间距、颜色 token、图标(cy-icon 的 coolicons 遮罩)都和 master 一致。只有每个原型自己的 `pN.css` 是本次提案,只用 master 的 token。
- **深浅**:玩家视角深色(`theme-dark`),商家视角浅色(`theme-merchant`),创作域浅色(`theme-topic-editor`,照 master)。帖文、资料页、关于页给了两套。
- **浮层**:按 iOS sheet,30% / 60% / 80% 三档(peek / half / full),点抓手在 60% 和 80% 之间切。
- **图片**:主题封面、头像、Tab 图标从 master 拷进 `assets/`;3D 图标来源与许可见 `assets/3d/README.md`。
- **珐琅勋章**:`tools/build-medal.js` 把 master 的 `subpackageP3/pages/badge-wall/index/{glyphs,enamel-pin}.js`(PR #653)原文件包成浏览器脚本,主题勋章在它上面加主题徽记,不另写渲染器。
- **截图**:`node docs/design/proto-dw29-20261029/tools/shoot.js`(Playwright + Chromium,2 倍图,打开「显示改动」),输出到 `shots/`,清单在 `shots/list.txt`。

3. **正文折叠**:6 行后出「更多」(现在是 2 行就「展开」)。6 行合适吗?
4. **图片**:单图按原比例(竖图最高 4:5,横图最矮 16:10);2 张以上横滑、等高 220pt、滑到屏幕右缘;5 张以上右上角「1/12」。同意吗?
