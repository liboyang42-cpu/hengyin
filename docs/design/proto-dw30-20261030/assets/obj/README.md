# 藏品物件图(原型用)

P-3 藏品堆里的物件。真机上藏品是玩家拍物成卡时从照片里抠出来的主体(`cutoutUrl`),原型没有玩家照片,用这些现成的抠图物件代替;外圈白色裁切边在原型里由 `p3.js` 的 `sticker()` 画上去。

来源:Microsoft Fluent Emoji,原始 3D PNG,未修改。仓库:https://github.com/microsoft/fluentui-emoji(`assets/<Name>/3D/<name>_3d.png`)。
许可:MIT,完整版权和许可见同目录 LICENSE(与 `assets/3d/LICENSE` 同一份)。

只在原型里用,不进小程序。
