# 动效与界面落地清单（2026-10-22 业主口述 → 代码）

来源：2026-10-22 业主与 Claude 的整段对话（12 版可点原型 https://claude.ai/artifact/BGPx8rAeoqHDWpLrzT4Au3 ，v13 定稿）。
原则：**不改既有页面版式**，只在原页面上加动效和业主点名的新块；数据只用现有接口，接口没有的字段不造假数据，对应块整块不出。

> **2026-10-23 业主改口径**：「要和 HTML 一模一样，除了护照页」。上面「不改既有页面版式」作废——漫游首页、打开地图、主题封面 / 详情三标签、购买半屏、确认订单、通行证到账、票夹、通关勋章，全部按 v13 原型的版式重做（护照页保持原样）。数据口径不变：只用真实接口字段，没有的字段整块不出。
> 逐屏对照截图：`v13对照截图_20261023/`（左 HTML 原型，右 DevTools 小程序）。
>
> 与原型仍有差异、需业主拍板或补数据的：
> 1. 地图底图是腾讯默认浅色。暗色底图要开个性化地图（2026-08-12 决定暂不开，约 400 元/月），开了以后 `utils/map-style.js` 填 subkey 即可，代码已接好。
> 2. 漫游首页底部 tab 栏是全站共用组件（没有文字标签），原型带「首页 / 玩法 / 漫游 / 消息 / 我的」文字；改它会影响所有 tab 页，没动。
> 3. 漫游首页三张入口卡的图是现有插画，原型是照片（仓库里没有可用照片素材）。
> 4. ~~购买半屏只有「单人」~~（2026-10-23 业主：票种名称取票种数据，不能空着）已改：半屏列出「自玩通行证」+ 发布者配置的每个票种（名称、价格、人数图标取票种数据，同名取最低价标「起」）。选票种后进选场次弹层并预选同名票；自玩通行证仍是一个价、不分人数。
> 5. 确认订单没有「俱乐部权益 / 积分抵扣」两行（没有这两项能力）；同意文案保持原有合规口径。
> 6. 通行证上没有「典藏」档位角标（没有这项数据）。
> 7. 通关勋章页四格统计只写拿得到的数（用时 / 步行 / 站点 / 解谜分）；「新纪录」只在解谜分超过个人最好时出。
> 8. 「主要角色」取各商家站点已过审的出场 NPC（`/api/ai/npc/profile`，新增 GET，需 C00 入矩阵）；没有 NPC 的主题整块不出。
> 9. 路线 tab 的小地图是按真实站点坐标画的深色示意图（不写路名），点一下打开真实地图。
验证：本次不碰微信开发者工具（2026-10-15 起的预算约束），以 `npm run test:unit` + lint 为证据，模拟器截图留给业主验收。
