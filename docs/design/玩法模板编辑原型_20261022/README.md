## 定稿要点

- 结构照小程序 `pages/publish/temp`：封面与名字 → 模板信息 → 玩法规则 → 参与方式 → 玩法 → 题目 / 作答规则 / 选项 → 结果反馈（成功、失败各一个开关）→ 完成奖励（优惠券、勋章）→ 互动工具（成功使用次数、限时挑战、语音讲解、背景音乐）→ 添加模块。
- 分区标题放在卡片外，标题前没有竖线；卡片内只有一层（白卡 + 浅灰输入框）。
- 新建模板直接打开选择玩法，名字默认取玩法名。
- 参与方式：扫码参与 / 直接参与 / 定位参与；扫码下面「扫完回复」单独一个开关。
- 选择玩法：半屏弹层，所有分类排成一条只左右滑，每类最多四行胶囊标签（Figma 标签样式，宽度随字数，带图标），选中灰底 + 对勾，底部是说明和预览。
- 下拉是贴着字段弹出的单列菜单，无分隔线；浮层头部左「退出」右「完成」对称；开关打开为绿色；只有玩法有图标；不用渐变色，只用透明度渐隐。
- 必填项红色 *（玩法、参与方式不标）；没有「核心」「推荐」标签；技能检定改名 D20。
