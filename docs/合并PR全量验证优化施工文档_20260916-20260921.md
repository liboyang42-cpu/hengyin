状态统一使用：

- `TODO`：尚未开始。
- `RUNNING`：正在验证或修复。
- `PASS`：该项要求和负控均有证据。
- `FAIL`：已复现缺陷，等待修复或复验。
- `BLOCKED`：缺账号、设备、产品拍板或外部状态，已写明解除条件。
- `N/A`：经代码和产品合同确认不适用，必须写理由。

`BLOCKED` 可带原因码，但状态仍只算 `BLOCKED`：

- `BLOCKED_DECISION`：等待产品/业务拍板。
- `BLOCKED_ENV`：缺精确运行环境、账号或设备。
- `BLOCKED_AUTH`：缺生产写入、真实资金动作或上传授权。
- `BLOCKED_EVIDENCE`：外部动作可能已发生，但尚无从对面读回的证据。

禁止使用“应该、看起来、理论上、CI 绿了”作为 `PASS` 证据。
