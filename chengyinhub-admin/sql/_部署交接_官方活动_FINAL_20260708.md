## 二、真机验收(部署后,用账号 100092)

### 小程序端(玩家 + 白名单发布)
1. 首页顶部出现**「城市事件」条**(有活动时显示倒计时+集体进度%)→ 点进列表
2. 列表右下「＋ 发起官方活动」(白名单可见)→ 配活动(开集体玩法+阈值+奖励)
3. 发布时**勾玩家/俱乐部/商家 + 选「分开发」写各自文案** → 提交
4. 目标账号的**消息中心**收到官方通知(站内信);点开 → 回流记录 clicked
5. 报名 → 详情「去探索·完成任务」→ 进度+1 → 集体进度条动
6. 列表头「我发布的」→ 看自己发的活动+通知**触达数**
7. 非白名单账号:看不到发布入口,调 /publish 返「无官方发布权限」

### Web 后台端(super admin 登录)
1. 左侧菜单「官方活动」→ 列表
2. 新建活动(全字段编辑器)/ 编辑 / 上线-下线 / **手动结算**(发奖)
3. 「通知」按钮 → 三角色勾选 + 一起/分开发 → 发送(返回触达人数)
4. 「数据」按钮 → 参与/完成/集体进度复盘
5. 「复制」按钮 → 一键复制为下期新活动

### 自动结算验(可选)
- 到某活动 `activity_end` 后 5 分钟内,sys_job 自动把它推进到结算态并发奖(或后台点「结算」手动触发)。
