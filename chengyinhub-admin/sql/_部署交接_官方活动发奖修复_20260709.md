## 五、部署后真机验收(发奖链路杀手锏)

1. **重复发放防线(P0-1)**:后台官方活动列表,对一个"结算中"活动**连点两次「结算」** → 查库 `sms_coupon_history` 该活动参与者的发券记录**每人仅 1 条**(修复前会 2 条)。
2. **丢奖可重试(P1-1)**:结算日志出现 `[官方活动] 单人结算失败(已回滚...)` 时,对应 `event_signup.reward_claimed` 应仍为 0(待重结算补发),而非 1。
3. **白嫖封顶(P1-4)**:小程序对单任务活动反复调"完成任务" → `event_signup.progress` 不超过任务总数,即时 XP 不再无限涨。
4. **通知触达真实(P2-1)**:发一条官方通知 → `official_broadcast_log` 中发送成功者 `reached=1`、失败者 `reached=0`;`reachStats` 的 reached 数 = 真实送达数。
5. **越权(P2-8)**:换一个白名单发布者账号调 `/broadcast/{别人的id}/stats` → 返回「无权查看该通知数据」。
